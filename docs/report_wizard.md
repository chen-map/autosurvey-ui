# 新建综述项目（详细版）

点击"新建综述项目"进入创建向导，用户根据界面指引分五步完成项目创建，如图 5-2、5-3 所示。

**第一步：选择研究领域。** 用户从领域标签库中勾选 1–3 个研究领域（如"多智能体协作""联邦学习""安全"），用于生成检索式与缺口分析的聚焦范围；标签库支持用户自定义扩展并跨会话持久化，系统还会自动预选上次使用的领域组合。若用户此前在方向库中保存过研究方向，也可直接选用，系统将自动带出对应的领域标签。

**第二步：填写主题与上传种子论文。** 用户填写综述主题与领域描述（系统支持中文主题自动生成英文检索词——由大模型理解中文语义后翻译为领域惯用的英文关键词组合，用户可逐条增删修改）；随后上传 1–3 篇代表性种子论文 PDF，系统从全文提取关键词构建 Golden Set 检索式，并以种子论文在检索结果中的覆盖率（≥80%）验证检索式的有效性，确保后续大规模检索不会偏题。

**第三步：合并本地资料（可选）。** 用户可批量上传手头已有的本地论文 PDF，系统将其统一并入语料库元数据，与在线检索结果一起进入后续筛选与分析流程，避免已有文献的重复获取。

**第四步：配置参数。** 用户可多选论文搜索平台（Semantic Scholar、arXiv、Google Scholar、ACM 等免费源与 IEEE、Springer、Elsevier 等订阅源——后者使用用户自备的 API 密钥接入，缺密钥的平台会被自动跳过并提示），并通过三个滑杆调节检索规模：检索量上限（200–2000 篇）、最终保留量上限（100 篇起，不超过检索量）与论文对预评分阈值（0.10–0.50，控制知识图谱构建阶段进入深度配对的论文对比例）。

**第五步：确认创建。** 系统汇总展示主题、领域标签、检索关键词、平台清单与各参数取值，用户核对无误后点击创建，项目即建立并进入综述生成流程。
