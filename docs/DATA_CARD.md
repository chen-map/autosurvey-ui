# 数据卡：AutoSurvey 真实运行快照

## 1. 数据集概述

本数据集是 AutoSurvey 在六个真实研究方向上的运行产物快照，用于公开展示“综述结论—证据论文—原文页码”的可追溯链路。数据为只读静态副本，不含后端服务、账号、访问凭据或服务器路径。

生成时间：2026-10-29。生成方式：完整运行检索、筛选、结构化、知识图谱、RQ 设计、逐题分析、综述写作与编译后导出。

## 3. 文件与字段

| 文件 | 内容 | 主要字段 |
|---|---|---|
| `manifest.json` | 项目清单与静态接口映射 | `projects[]`、`endpoints[]` |
| `corpus.json` | 语料与筛选漏斗 | `papers[]`（题录、状态、六类结构化字段）、`funnel[]` |
| `kg.json` | 论文关系图 | `nodes[]`（Paper/Problem/Method/Dataset/Metric/Limitation/Assumption）、`edges[]`（继承、比较、支持、矛盾等） |
| `rqs.json` | RQ 与证据 | `macros[].subs[]`（证据强度、冻结论文）、`claims[]`（结论、四维核查、来源）、`sources[].evidence[]`（短引文、页码、截图路径） |
| `report.json` | 大纲与评审 | `outline[]`、`reviews[]` |
| `reports.json` + `w4/*.html` | 逐 RQ 分析报告 | 技能、轮次、工具调用统计、报告正文 |
| `survey.pdf` | 生成的英文综述全文 | — |
| `evidence/*.jpg` | 引文定位条带 | 文件名与 `rqs.json` 中的 `image` 对应 |

## 4. 采集与处理

- 文献来源：公开学术检索接口与开放获取 PDF；用户可另行上传自有文献。
- 处理流程：检索 → 归一去重 → 六阶段筛选 → PDF 下载 → 解析 → 六类结构化抽取 → 论文对关系判断 → 知识图谱 → RQ 设计与证据矩阵 → 逐题分析 → 综述写作与编译。
- 公开版处理：移除论文摘要批量文本；证据图仅保留定位引文所需的页面条带；移除账号、路径、模型配置与访问凭据。
- 关系图为展示性能做过子图截断（概念节点约 600、边约 1800），不是完整图。

## 5. 许可与权利

- 团队生成的结构化标注、分析文本与综述：CC BY 4.0（见 `LICENSE`）。
- 论文题录、DOI、短引文与页面片段：权利归原作者/出版方，仅用于引用核验；不包含论文全文。
- 如权利方提出异议，可下线对应条目。

## 6. 隐私与安全

- 不含个人信息、账号、邮箱、API Key、服务器地址或内部路径。
- 不含用户上传的私有文献。
- 公开快照与生产环境隔离，生产系统不对公网开放。

## 7. 已知局限

- 生成文本由模型辅助完成，可能存在事实或表述错误；数据集展示的是可追溯流程，不构成学术结论。
- 证据定位为**论文级**回溯（引文—论文—页码—条带），不是逐句语义归因。
- 评审对照样本有限，评估结论只代表当前小样本。
- 关系图经过截断，统计数字与完整图不一致时以完整系统为准。

## 8. 维护

快照由私有流水线导出；更新时重新生成 `public/showcase/` 并保持字段兼容。字段变更需在 `manifest.json` 中标注版本。
