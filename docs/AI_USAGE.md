# AI 工具使用说明

本文件按赛事要求，说明生成式人工智能、智能体与自动化工具在本作品中的用途、参与环节，以及团队的审核、修改与验证工作。

## 1. 使用范围

| 工具类型 | 具体工具（示例） | 参与环节 | 产出 | 人工审核与验证 |
|---|---|---|---|---|
| AI 编程助手 | ZCode、Claude Code 等（以团队实际使用为准） | 前端页面、API 适配、脚本重构、文档草稿 | 代码片段、测试、文档初稿 | 逐文件人工审阅；`tsc --noEmit`、`npm run build`、`pytest`、接口联调；关键逻辑由团队成员改写与复核 |
| 运行时大模型 API | DeepSeek、Anthropic 等（可在系统内配置） | 论文结构化抽取、RQ 设计、逐题分析、综述初稿 | 六类结构化对象、分析文本、章节草稿 | 证据矩阵约束；引用闭合检查；数字回查；自动审查轮次；人工抽检与修订 |
| 自动化脚本 | 检索、去重、筛选、PDF 解析、证据对齐、编译 | 语料构建、证据定位、PDF 生成 | 语料库、证据索引、LaTeX/PDF | 单元测试与冒烟测试；统计定位成功率；失败样本人工复核 |
| 图像/排版 | 系统内置图表与 LaTeX 模板 | 报告图表、综述 PDF | 图表与 PDF | 模板化生成，不含第三方图片；人工检查版式与引用 |

## 2. 不作为团队自主知识产权的部分

- 模型生成的文本、分析、图表与 PDF 内容，不当然认定为团队自主知识产权；其使用受所调用模型/平台的服务条款约束。
- 第三方论文的题录、DOI、短引文与页面片段，权利归原作者/出版方；本作品仅在引用核验所需的范围内使用。
- 开源组件与模板按其许可证使用，团队未主张对其享有权利。

## 3. 团队的实质工作

- 系统架构、阶段划分、证据矩阵与质量门设计、人工闭环流程由团队完成。
- 对 AI 生成内容执行“可追溯”约束：关键结论必须绑定证据论文；引用必须闭合；数字必须能回查；不满足条件的结论删除或降级。
- 评测方案、评分表、参照综述选择与结果分析由团队设计并执行。
- 所有提交的代码、文档与演示材料均经团队成员审阅、修改和验证。

## 4. 验证方式（可复核）

- 前端：TypeScript 类型检查与生产构建通过。
- 后端：关键路径单元测试与接口联调；失败重试与空输出拦截。
- 证据链：对导出项目统计“引文—页码—截图”的定位成功率（例如某项目 412 条引文中 391 条成功定位），未定位条目在界面标注，不伪装为已核验。
- 公开演示：以真实运行快照复现，不依赖现场调用模型。

## 5. 声明

团队遵守所使用模型、平台与 API 的适用许可和服务条款；AI 生成内容已进行来源与权利核查；如后续发现不当内容，将及时修正或下线。
