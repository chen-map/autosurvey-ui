## 设计基调

**"黑白账本，彩色证据"**——框架 chrome（导航/表格/表单/按钮）全黑白灰（xept 实拍语言），色彩只出现在三类**语义内容**上：KG 六类节点、流水线状态、claims 核查结果。答辩时画面上的每一种颜色都在传递证据信息，没有装饰色。

### 语义色板（"内容即色彩"的三组）

**KG 六类节点**（白底上可区分、色盲相对安全）：

| 节点 | 色 | 节点 | 色 |
|---|---|---|---|
| Paper 论文 | `#111111`（黑，视觉锚点，尺寸最大） | Metric | `#9333ea` |
| Problem | `#2563eb` | Limitation | `#dc2626` |
| Method | `#16a34a` | AssumptionConstraint | `#0891b2` |
| Dataset | `#d97706` | | |

**边类型**：extends 实线灰 ｜ compares_with 虚线灰 ｜ supports 细绿实线 ｜ background 点线浅灰 ｜ **contradicts 红色实线加粗**（答辩钩子，永远最后被隐藏）

**流水线状态**：pending `#d9d9d9` ｜ running `#1677ff`（脉冲动画）｜ done `#16a34a` ｜ failed `#dc2626` ｜ checkpoint `#d97706`

**claims 核查**（design-db 标签公式：浅底+同色相深字）：verified 绿 ｜ needs_revision 琥珀 ｜ should_remove 红+删除线置灰

## 反幼稚审计预检

①功能位零 emoji（图例/状态全部图标库+色点）②色彩=黑品牌+三组语义色，无装饰色 ③文本四级层级、正文对比度 ≥4.5:1（置灰节点 8% 透明度仅用于视觉降噪，不承载信息）④圆角三档 ⑤间距 4/8 栅格 ⑥层次：画布 L1 卡片、侧栏 L1、浮层卡 L3+scrim ⑦字阶 ≤7 档 ⑧画布/表格容器 overflow 规则、`min-width:0` ⑨1px 边框 token、focus 黑色 ring ⑩每屏一个 primary（画布页的 primary 是「按 RQ 高亮」）。
