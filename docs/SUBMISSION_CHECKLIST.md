## 2. 五分钟演示视频脚本

| 时间 | 内容 | 要点 |
|---|---|---|
| 0:00–0:20 | 问题 | 综述写作不缺生成，缺可信；引用错比写得平淡更严重 |
| 0:20–0:50 | 方案 | 检索 → 结构化 → 关系图 → RQ/证据矩阵 → 写作 → 质检 |
| 0:50–2:20 | 在线演示 | 选真实项目 → RQ → claim → 原文页码/条带；看漏斗、关系图、PDF |
| 2:20–3:20 | 私有系统录屏 | 启动、进度、人工修订、重评、断点续跑（不展示密钥/路径） |
| 3:20–4:10 | 开放成果 | 37 个分析规范、数据卡、评测材料、开放计划 |
| 4:10–4:40 | 边界 | 论文级回溯，不是逐句归因；样本有限；不替代研究判断 |
| 4:40–5:00 | 结尾 | 不是让 AI 替人写综述，而是让 AI 帮人把证据管起来 |

录制要求：不出现学校名称/校徽/导师；浏览器书签、桌面、通知、路径全部清理；不展示 API Key。

## 3. 评委十分钟体验路径

1. 打开 <https://chen-map.github.io/autosurvey-ui/>，点「直接进入公开数据演示」。
2. 进入「面向小农的农业人工智能」项目，查看 RQ 与证据强度。
3. 打开任一 claim，核对论文、页码与原文条带。
4. 查看语料漏斗、论文关系图、评审记录与 PDF。
5. 打开「开放数据」页，下载 `rqs.json` / `survey.pdf`。
6. 阅读 `open/analysis-skills/README.md` 与 `docs/OPEN_SOURCE_PLAN.md`。
