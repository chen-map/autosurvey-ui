## 2500+ 节点的升级路径（tech-stack.md 备选项）

1. **画布层换 Cytoscape.js**（canvas 渲染，万级节点流畅）——仅替换画布，过滤/联动逻辑不变
2. **布局移入 Web Worker**——构建不阻塞主线程，加载期间显示骨架
3. **渐进加载**——先渲染度数最高的 Top-N 节点，缩放/筛选时增量展开

## 决策

当前真实目标 500 节点 → React Flow 方案 ✅ 达标（构建 294ms，交互流畅）。
500 论文（2500 节点）以上场景启动升级路径前，先与用户确认真实数据量。
