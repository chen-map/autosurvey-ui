# 多角色工作流推演 · AutoSurvey 前端控制台

> 日期：2026-09-10 ｜ 规模 L ｜ 角色清单已经用户报备确认（含追加的管理员）

## 角色清单

| 角色 | 来由 | 权限边界 |
|---|---|---|
| 研究者/答辩人 | 核心用户，确认于裁决轮 | 建项目、跑流水线、浏览全部产物、操作重跑 |
| 观众/评审（只读） | 演示/答辩场景推导 `[推断]`，随角色报备默认通过 | 只读浏览全部页面，操作按钮隐藏；防投屏误触 |
| 管理员 | 用户裁决追加 | 全项目总览 + 用户列表（深度用户管理 `[推断]` 延后 v2） |

## 角色一：研究者/答辩人

### 主路径
1. `/login` 演示账号登录（黑白登录卡，xept 同款范式）→ `/projects` 项目列表（卡片栅格+进度摘要）
2. `/projects/new` 创建向导：综述主题 → 种子论文上传（PDF 校验）→ 本地论文合并（W1 P7）→ 参数配置（检索式/prescore 阈值/筛选档位）→ 创建
3. `/projects/:id/pipeline` 流水线：5W 分段进度 → Phase 级状态点 → 实时日志（按 Phase 过滤）→ 失败 Phase「从 checkpoint 重跑」→ 规模指标卡
4. `/projects/:id/corpus` 语料库：PRISMA 漏斗（数万→数百→百余）→ 论文表（Elicit 式）→ 点行进 `/papers/:pid`
5. `/papers/:pid` 论文详情：元数据 + PDF 预览 + Paper Card 六类对象标签页【W2】
6. `/projects/:id/kg` KG 画布：6 类节点分色 → 边类型筛选（contradicts 红色强调）→ 点节点联动侧栏 → 按 RQ 高亮子图【W2·视觉中心】
7. `/projects/:id/rq` RQ 树 + Answerability 分卡 + 冻结矩阵（"已冻结"徽标）→ 点 Sub-RQ 进证据页
8. `/projects/:id/rq/:rqid/evidence` 证据池（≥5 篇达标提示）+ overall_answer + claims 四维核查列表，点 claim 展开追溯链（论文原文位置 + KG 节点）【W4·讲解核心】
9. `/projects/:id/report` 大纲章节树（章节→RQ→论文）+ main.pdf 内嵌预览/下载 + 审查轮次记录
10. `/projects/:id/agent` Agent 控制台：输入 RQ → Skill 选择过程（37 选 1 理由）→ agentic loop 工具调用时间线 → HTML 报告内嵌 + tool_log

### 分支
- 后端未就绪：全站数据来自 mock 层，导航栏常驻「DEMO DATA」徽标（防演示时误以为真数据）
- Phase 失败：状态点转红 + 日志定位错误 + checkpoint 重跑按钮
- 上传校验失败：非 PDF/超大小 → 上传区行内报错（边框转 `--danger`，不弹 alert）
- 空状态：无项目/无论文/claims 全通过等各有空态插画 + 引导按钮

## 角色二：观众/评审（只读）

### 主路径
1. 答辩人投屏后切换「演示模式」，或直接分享 `/projects/:id` 只读链接
2. 全部浏览页可看：漏斗、KG 画布、claims 追溯链是三个预设讲解锚点
3. 所有写操作（创建/上传/重跑/输入）按钮隐藏；只读徽标常驻

### 分支
- 只读身份访问 Agent 控制台 → 可看历史报告，不可发起新分析

---

## 角色三：管理员

### 主路径（最小集 `[推断]`，深度功能延后 v2）
1. 管理员账号登录 → 顶部出现「管理」入口
2. `/admin` 全项目总览（跨项目进度/规模对比）+ 用户列表（账号/角色/停用开关）

### 分支
- 非管理员访问 `/admin/*` → 403 页（黑白风格 + 返回按钮）
- 停用账号登录 → 行内提示拒绝

## 角色间数据流转（自检第三问）
- 研究者创建项目 → 管理员总览即时可见（同一数据源，轮询刷新）；观众只读同一份只读视图
- 研究者重跑 Phase → 语料库/KG/claims 数据随之失效 → 页面顶部出现「数据已过期，基于 checkpoint N」提示条（v2 联动点：本次仅静态提示，不做细粒度失效追踪）
- 后端未就绪期的统一约定：所有角色读同一 mock 数据包，接口形状即未来 API 契约

## 推演中发现的缺口（已回补）
- 答辩场景需要"讲解锚点"：claims 追溯链、contradicts 边、PRISMA 漏斗三处做演示友好设计（大字号/可逐步展开）
- mock 数据必须覆盖"全流程已完成"与"W3 进行中"两个快照（答辩讲到哪演到哪）
