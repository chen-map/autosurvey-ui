## 剪辑总则

- **所有等待剪掉**：加载、流水线运行、检索词生成、PDF 渲染——只留结果出现后 2 秒
- 滚动列表 1.5–2x；正文阅读原速
- 配音语速 220 字/分，全稿 ~830 字 → 正好 3:50
- 导出：`ffmpeg -i raw.mp4 -vcodec libx264 -crf 26 -preset medium out.mp4`（≈100-150MB）
