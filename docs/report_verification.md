# （二）验证方法

本系统采用多层次验证策略，从引用完整性、证据可溯源性、生成质量三个维度对综述输出进行验证。

**引用闭环校验。** 系统在综述编译前执行引用闭环审计：扫描正文全部引用键，与参考文献列表进行双向对账，确保正文引用的每一条文献均存在于参考文献列表中，参考文献列表中每一条均可在正文中找到对应引用点。对账不一致的引用被标记为未解析并自动修复（缺失条目从语料元数据补录、畸形条目从权威数据源重建）。最终以 LaTeX 编译器的 undefined citation 警告数量作为硬性指标，要求归零。

**证据可溯源性验证。** 每条研究论断（claim）在生成时即标注支撑文献的标识符，读者可通过论断中的引用标记回溯到冻结证据集合中的具体论文。系统维护从论断到文献的双向索引：正向查询可列出某篇论文支撑了哪些论断，反向查询可列出某条论断引用了哪些论文。对于因下载受限而缺少全文的文献，系统在证据档案中标注其获取状态，不影响已下载文献的证据完整性。

**生成质量评估。** 采用 AI-as-Judge 方法对生成的综述文本进行自动化质量评估，评估协议参考 arXiv:2607.04439 提出的大语言模型裁判框架。评估维度包括新颖性（ Novelty ）、可靠性（ Soundness ）、清晰度（ Clarity ）等，每个维度按 1–10 分制评分，并映射到 L1–L5 五个质量等级。评估由独立的大语言模型实例执行，与生成模型分离以减少自评偏差。此外，系统内置了自动自审机制：在综述正文生成后，由大语言模型以审稿人视角对输出进行自审，识别格式残留、内部术语泄漏和结构缺失等问题并自动修正。

# （三）验证结果

引用闭环校验通过。最终综述论文包含 350 余处引用，参考文献列表收录 119 条来自冻结语料库的文献条目，编译器的 undefined citation 警告为零。所有正文引用与参考文献列表完全对账，无悬空引用或占位条目。

证据可溯源验证通过。知识图谱纳入的 186 篇文献全部完成六类概念实体提取（问题、方法、数据集基准、指标、局限、假设约束），共产出约 1,830 个概念节点和 3,196 条语义关系边。研究问题分析阶段产出的 120 条论断均标注了支撑文献标识符，通过系统提供的双向索引可从任意论断回溯到具体的源文献。

生成质量评估初步通过。以 AI-as-Judge 协议对生成的综述论文进行了抽样评估，评估维度包括新颖性、可靠性、清晰度等。抽样评估结果中，新颖性维度得分为 6/10（对应等级 L3），表明生成的综述在覆盖已知工作的基础上具备一定的增量分析能力，但在突破性见解方面仍有提升空间。由于评估尚处于初步阶段（当前仅完成单篇样本的完整评估），后续将扩大评估样本量并引入人工评审作为补充验证手段。
