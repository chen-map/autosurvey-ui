# 报告文档改写版（与系统实际实现对齐）

本作品针对自动综述写作领域的主要问题，构建以知识图谱为核心的证据组织与核验体系。结合实际应用的需求，采用智能体驱动架构、声明级证据锚定与引用闭环核查等机制，实现证据可追溯、结果可复现、内容可核查的综述生成系统。

系统主要分为证据底座、问题规划与分析、写作与交付三个层次。证据底座层负责构建语料库、解析全文、生成可查询的知识图谱；问题规划与分析层负责将综述目标转化为可由证据回答的研究问题，预先固定每个问题的证据范围，通过智能体逐子问题调用分析技能与知识图谱工具开展深入分析；写作与交付层按主题重组分析结果并组织章节、生成领域数据图表、撰写 LaTeX 正文、编译并执行引用闭环与格式自动校验。项目架构图如图 2-1 所示。

图 2-1 项目架构图

用户需提供综述主题、种子论文以及本地 PDF 等数据作为系统输入，可在网页中设置论文检索时间范围、检索量与语料量上限、知识图谱配对规模等要求；系统内置 arXiv 优先、开放学术索引兜底的双通道检索与多级下载降级策略，各工作流可独立配置不同的大模型接口，事实记忆构建默认使用服务器本地模型以降低成本。获取基础数据后，系统依次经过五个工作流，输出最终论文。系统工作流如图 2-2 所示。

图 2-2 系统工作流

语料库构建与事实记忆构建属于证据底座层，两个工作流共同形成整个流程可复核的证据基础：前者完成多源检索、筛选下载与语料库对账，后者从全文中提取问题、方法、数据集基准、指标、局限、假设约束六类概念实体及其语义关系，构成论文级知识图谱。综述框架与研究问题设计将主题转化为现有证据能够回答的研究问题，并对证据不足的子研究问题自动改写、放宽检索范围，由知识图谱结构关系补齐证据后冻结综述大纲与证据矩阵。研究问题分析与论文撰写在固定证据范围内开展：先按内容亲缘将全部子问题聚类重组为若干主题章，再由写作智能体逐节深入撰写，图表由知识图谱数据直接投影生成（如评测基准与指标格局、方法演化谱系、失效模式分布），最后编译并执行引用闭环校验——正文引用与参考文献强制对账，未解析引用自动修复。各模块通过文件化的中间状态衔接并支持断点续跑，任务中断或机器重启后可从最近状态自动继续，无需重新完成全部处理。最终输出由作者对文献范围、关键论述、引用、图表和格式进行人工复核。
