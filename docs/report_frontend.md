# 前端设计（详细版）

前端采用 React 18 框架开发，使用 TypeScript 作为主要开发语言。相比传统的 JavaScript，TypeScript 在编译阶段即可发现类型错误，减少了运行时故障的发生。工程化构建选用 Vite——相比早期的 Webpack，Vite 的冷启动与热更新速度明显更快，能够支撑开发阶段的频繁修改与调试。样式管理采用 Tailwind CSS，通过原子化的 CSS 类进行页面布局，避免了传统 CSS 方案中样式命名冲突与冗余代码的问题。状态管理引入了 Zustand 库，用于处理知识库收藏、用户认证状态等需要跨页面共享的数据，相比 Redux 更加轻量且易于上手。知识图谱的可视化渲染基于 @xyflow/react 图编辑库实现，支持节点拖拽与交互式探索。此外，页面中的图标采用 lucide-react 图标库，Markdown 内容的渲染使用 react-markdown 组件。

整个前端共包含 16 个页面组件，全部代码约 5400 行（TypeScript/TSX 格式）。这些页面按照用户的使用流程可划分为六个模块：一是账号认证模块，包含登录、注册与密码找回三个页面；二是项目管理模块，包含项目列表与五步式创建向导；三是流水线监控模块，用于实时展示语料库构建、知识图谱构建、综述框架设计、研究问题分析与论文撰写五个工作流的执行进度；四是知识图谱与研究问题模块，负责图谱的可视化展示与研究问题证据的溯源查询；五是知识库与研究方向模块，提供论文收藏与选题管理功能；六是报告交付模块，负责综述论文的预览与下载。

页面布局采用"左侧固定导航栏 + 右侧内容区"的经典结构。左侧导航栏包含全部项目、知识库、研究方向、个人中心四个功能入口，管理员账号额外可见管理后台入口，可查看全部用户的项目列表与活跃状态。右侧内容区根据当前路由动态渲染对应的页面组件；在项目详情视图下，页面进一步嵌套子布局，包含流水线监控、知识图谱可视化、研究问题证据、语料库管理与综述报告五类子页面，用户可在不同子页面间快速切换。

在账号认证方面，系统采用基于令牌（Token）的会话管理方式。用户在登录页输入用户名与密码后，前端将凭证提交至后端 API 进行校验；校验通过后，后端生成一个有时效的会话令牌返回给前端，前端将其保存在浏览器的本地存储中，后续每次请求均在请求头中携带该令牌以完成身份验证，令牌过期后自动引导用户重新登录。注册流程要求用户绑定邮箱地址，用于后续的密码找回——用户点击"忘记密码"后，系统通过 SMTP 服务向绑定邮箱发送一次性重置链接。密码本身在服务端经过加盐的 PBKDF2 算法（迭代 10 万次）哈希后存储，任何人都无法从存储值反推出原始密码。

在数据交互方面，前端与后端通过 RESTful API 通信，所有请求封装在独立的 API 模块中统一管理。对于语料库这类大规模数据的展示，页面采用服务端分页与按状态筛选的策略——每次只请求当前页的数据，避免一次性加载数千条记录导致浏览器卡顿。开发阶段支持模拟数据模式与真实后端模式的切换：模拟数据模式下前端不依赖后端即可独立运行，便于界面的快速迭代；生产环境构建时通过环境变量切换至真实接口。构建产物为纯静态文件（HTML/JS/CSS），可直接部署于任意 HTTP 服务器上，无需额外的运行时环境，也支持后续迁移至 Docker 容器或 CDN 加速等部署方案。
