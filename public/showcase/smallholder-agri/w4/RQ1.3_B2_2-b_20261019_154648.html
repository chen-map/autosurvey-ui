摘要

本报告针对 RQ1.3「多智能体/神经符号系统如何衔接感知与决策建议，是否触及采纳环节？」展开分析。核心结论是：多智能体与神经符号系统在「感知→决策建议」链路上已相当成熟，部分系统甚至实现了闭环执行，但几乎没有任何一个技术系统真正触及采纳环节，即从「给出建议」到「农户实际执行并产生行为改变」的最后一公里。采纳环节的实证证据全部来自社会科学与因果推断研究，而非系统论文本身，且一致表明决定采纳的关键因素是投入品可得性与资金约束；建议质量并非决定性因素[1][2][3]。

感知→建议的衔接在技术上已完成，并分化为三条架构路线：对话式多智能体编排（PhenoAssistant 工具选择成功率 70%、视觉模型选择 98%[4]；PhenoIntel 以九代理架构将计数误差降低 54%、检测 mAP@50 达 0.96[5]）、神经符号双引擎（PhenoNest 将 LLM 感知与 LLM 逻辑引擎解耦，产出对齐 PO/RO/WTO 本体的知识图谱[6]），以及闭环控制型（Closed-loop LLM Co-Pilots 通过 49 通道传感器触发执行器，生产周期缩短 35%、能耗降低 18%[7]）。三条路线的输出终点均落在测量值、分析结论或执行指令，而非农户决策采纳。

感知→建议的衔接：三条架构路线已成熟，但终点不在采纳

第一条路线是**对话式多智能体编排**。PhenoAssistant 以 LLM 为核心 manager，调度视觉模型库与数据分析工具箱，将自由文本任务转为可执行流水线，实测工具选择成功率 70%、视觉模型选择 98%、数据分析任务全部完成——但 70% 的工具选择率意味着近三成请求会被错误编排[4]。其继任者 PhenoIntel 用九代理生命周期架构（共享类型化 session state、V0–V7 验证检查点、按模型族匹配的不确定性量化）将失败前置拦截，报称计数误差降低 54%、检测 mAP@50 达 0.96，并明确指出同类单体编排器存在约 30% 的工具选择错误率[5]。

第二条路线是**神经符号双引擎**。PhenoNest 将 LLM 视觉感知与 LLM 逻辑引擎显式解耦，产出对齐 PO/RO/WTO 本体的多模态知识图谱，并用二元一致性门控（视觉检测标签与田块笔记文本符号对齐才允许写库）保证每个符号关系都有视觉证据背书——这是本证据集中唯一严格意义上的神经符号系统[6]。其局限是评估仅 500 样本、单一小麦作物。

第三条路线是**闭环控制型**。Closed-loop LLM Co-Pilots 让 LLM 直接解析植物传感器数据并触发硬件执行器，以 2 小时再评估周期形成「AI–生物」直接接口，实现生产周期缩短 35%、能耗降低 18%、自主策略额外节能 67.9%[7]。但作者明确承认人类专家验证仍不可或缺，且观察到模型会产生算法幻觉、无法验证其执行的是否为所声称的优化算法。

三条路线的共同点是：输出终点都落在测量值、分析结论或执行指令，服务对象是科学家或机器而非农户决策采纳[4][5][6][7]。

采纳环节：系统论文普遍未触及，社会科学揭示了断点所在

PhenoAssistant 与 PhenoIntel 的输出是「checked trait measurement + 置信区间 + 可审计记录」，服务对象是植物科学家而非农户[4][5]；PhenoNest 的输出是供研究者做多模态检索的知识图谱[6]；即使闭环系统也明确指出人类专家验证仍不可或缺[7]。真正触及采纳端的唯一技术论文是 AIEP 系列：其 800 农户研究显示满意度 NPS≈60，但在未采纳建议的农户中，50% 归因于投入品不可得或资金约束、33% 表示信息不易理解，低教育水平者更甚；作者直言「AI 咨询除信息外还需与其他缓解约束的服务集成」[8]。其后续工作通过 LoRA 在专家校验事实单元上微调，并加入「缝合层」解耦事实检索与对话交付，以提升事实召回与安全性[13]。

这与拖拉机服务研究的发现完全同构：79.7% 采纳，但剩余 20.3% 未采纳者的首要障碍是资金约束，且采纳缺口溢价（ATT GH₵471/英亩 vs ATU GH₵312/英亩）表明非采纳是结构性约束而非意愿问题[2]。农业保险研究进一步给出「接受—可得性悖论」：90% 农户认为有用，仅 14% 获得，64% 因不了解产品、23% 因产品在该地区根本不可得[3]。气候智能农业综述与数字技术利用综述则分别将障碍归纳为资金/信息/农场规模三项，以及终端用户/服务提供者/数字技术特征三类[11][12]。

关键洞察：把「建议」与「采纳」两个环节连接起来的仅有因果推断评估，而非系统设计。因果推断框架基于 2021 年棉花合作社数据、后门准则因果图与四种估计方法，估计按建议播种的地块产量提升 12–17%（372–546 kg/ha），并通过四项反驳检验[1]；其扩展工作在 171 地块上复现出 372–546 kg/ha 的 ATE[14]。但这属于评估采纳效果的框架，而非促成采纳的系统，且自身承认观察性研究可能受未观测混杂影响、限于单一作物与地区。

分析局限性

其一，**术语缺口**：本 RQ 冻结的六篇论文中没有任何一篇是「多智能体/神经符号」系统论文，多智能体与神经符号证据全部来自 KG 相邻文献（0082/2996/2978/2990/2976/2950），证据矩阵本身对 RQ 的直接支撑是间接的。

其二，**「采纳」定义漂移**：技术论文的 adoption 多指工具使用或满意度（如 NPS、采用率），社会科学论文的 adoption 指行为改变与持续使用，二者不可通约，导致「是否触及采纳」的判断依赖定义。

其三，**闭环≠采纳**：闭环执行系统实现了机器层面的行动闭环，但绕过了农户主体，不能视为对「农户采纳」的解答[7]。

其四，**定量证据稀缺**：AIEP 明确表示下一步才是对产量与生计影响的严格评估，即目前尚无量化的「AI 咨询→农户增产」因果证据；唯一有量化采纳效果的是传统天气建议系统[1][14]，而非多智能体系统。

其五，**系统性局限**：PhenoNest 仅 500 样本、单一小麦作物[6]；PhenoAssistant 受 LLM 能力约束需仔细拆解任务[4]；PhenoIntel 全部结果在单台无 GPU 机器上产出、部分指标非统一划分[5]。

结论

多智能体与神经符号系统已经把「感知→决策建议」做到可用：PhenoAssistant/PhenoIntel 证明对话式编排可自动化表型工作流但仍受 30% 级工具选择错误率制约[4][5]；PhenoNest 证明神经符号本体对齐可为符号推理提供像素级视觉背书[6]；闭环 Co-Pilot 证明 LLM 可驱动硬件执行闭环[7]。然而这三类系统的输出终点一律停留在测量值、分析结论或执行指令，服务对象是科学家或机器，而非农户。

「建议→采纳」仍是一片需要跨学科（技术+投入品+金融+语言）才能填补的空白，且当前没有任何多智能体/神经符号系统被证明能独立跨越它。社会科学证据一致指向：采纳瓶颈在投入品可得性与资金约束而非信息质量——AIEP 中 50% 未执行者是因物资/资金；拖拉机采纳中资金约束普遍绑定；保险中 90% 有用 vs 14% 获得的悖论[2][3][8]。唯一量化「建议→行为→产出」的是因果推断框架（12–17% 产量提升），但它是评估工具而非促成机制[1][14]。对 RQ1.3 的回答因此是条件性的：**系统已衔接感知与建议，但未触及采纳；『田间就绪性』在采纳环节的真实边界由农户端的经济与可得性约束划定，而非由算法能力划定。**
