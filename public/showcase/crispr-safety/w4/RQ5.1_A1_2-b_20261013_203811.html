摘要

本题（RQ5.1）考察父问题 RQ5 的一个子命题：LLM 安全侧已成熟的度量与概念（Attack Success Rate、Aleatoric uncertainty、Epistemic uncertainty、Bootstrap 与 Δ-Method 不确定性分析、以及「Aggregate K-Bench scores are comparative, not universal safety thresholds」这一认识论约束）中，哪些可映射到 CRISPR 临床前安全评估的对应量。本报告以「定义驱动推演」（definition-driven inference）为方法学视角，即以每个已形式化/半形式化的概念为公理起点，向问题空间演绎其约束后果，而非从问题观察反向归纳。

核心结论：五个概念**全部存在可迁移的对应量**，且迁移强度均为「强」——但迁移发生在**结构与方法论层面**（算子结构、约束逻辑、统计推断方法），而非**数值层面**（具体分值、阈值、量纲）的等价。具体而言：ASR 可结构同构地映射为 CRISPR off-target activity/mutation rate [1][2]；Aleatoric uncertainty 可映射为个体基因组背景造成的不可约 off-target 风险 [3]；Epistemic uncertainty 可映射为 off-target 预测模型的泛化缺口 [4][5]；Bootstrap 与 Δ-Method 可迁移为 off-target 基准指标的置信区间与敏感性分析 [6][7]；K-Bench 的「比较性而非阈值性」告诫可无损迁移为「off-target 预测分数仅用于相对排序，不得作为患者安全绝对阈值」[8][9]。

关键限制：全部结论为**方法论层面的逻辑推断，而非实证证明**。知识图谱中无任何 violates/instantiates 边直接桥接 LLM 安全概念与 CRISPR 安全量；且被冻结的框架论文评估的是「LLM 自身安全性」，而「用 LLM 预测 CRISPR 风险」是不同任务，迁移需额外的中间假设。

核心分析：五条定义→问题映射链

依「定义驱动推演」要求，对每个核心概念先提取其形式化约束结构，再演绎其在 CRISPR 安全语境下被违反/实例化时必然对应的问题类别。五条映射链的推导如下：

**（一）ASR → off-target activity/mutation rate（结构同构）**。ASR 的形式化定义为「五点评分中≥4 的场景占比」[1]。CRISPR 侧的 off-target mutation rate 定义为「非预期突变的频率」[2]，两者共享同一算子结构：分母=被检验的候选位点/场景集合，分子=被判为「有害/成功」的事件。故 ASR 可直接迁移为「CRISPR off-target 命中率」。约束：迁移必须显式携带评分函数，因为 ASR 分子由 rubric 锚定，而 off-target 的「active」判据随数据集而变（Change-seq 用 reads>100，GUIDE-seq 把全部实验鉴定位点标为 active）[11]。

**（二）Aleatoric/Epistemic 二分 → off-target 风险的可约简性分解（价值最高）**。KG 给出标准定义：Epistemic「源于知识缺乏，可通过获取更多知识/数据减少」；Aleatoric「系统中固有、不可通过更多知识/数据减少的变异性」。CRISPR 侧有近乎完美的同构对应：aleatoric ← 个体基因组背景造成的不可预测 off-target（同一 guide 在一人中安全、另一人因 SNP 产生近匹配位点）[3]；epistemic ← 预测模型训练数据不足带来的泛化缺口 [4][5]。由此得强蕴含：epistemic 风险可通过更大规模、跨检测平台数据约简 [4]，aleatoric 风险不可靠增加数据消除，只能通过患者特异性评估管理 [3]。

**（三）Bootstrap 与 Δ-Method → off-target 基准指标的置信区间与敏感性分析**。0460 详载 trial-level 10,000 次 bootstrap、95% CI 取 2.5–97.5 百分位、Δ-Method 对 σ_Corr=0.05–0.20 做敏感性扫描 [6]。CRISPR 侧指标波动更剧烈（同一编码在 CHANGE-seq 与 GUIDE-seq 上 AUPR 从 0.345±0.148 到 0.661±0.239）[11]，这些 ±sd 正是应被 bootstrap/Δ-Method 量化的对象。

**（四）K-Bench「比较性而非普适阈值」→ off-target 预测分数「比较性而非安全阈值」**。KG 假设节点明确「85.27 分本身不能确立安全，小差异未必有临床意义」，原文出处强调「Aggregate K-Bench scores are comparative, not universal safety thresholds」[8]。其移植对应为：off-target 预测分数仅用于 sgRNA 相对排序，不得作为患者安全的绝对阈值 [9]。

**（五）迁移的根本缺口**。0469 评估的是「LLM 自身安全性」（越狱/隐私漏洞）[1]，而「用 LLM 预测 CRISPR 风险」是不同任务；后者需额外的「LLM 可作可靠风险预测器」假设，KG 中无直接支撑。

对抗性验证：三条量纲不可通约的告诫

定义驱动推演最容易犯的错误是「跳步」——跳过中间推导直接声明结论。对上述五条映射链做对抗性检验后，确认三条必须标注的「外部假设」/量纲警告：

（1）**量纲不可通约**。ASR 分母是数十至数百的人为攻击场景，off-target rate 分母是 Cas-OFFinder 在 6 mismatch 内的搜索空间（CHANGE-seq 67,476 active vs 2,806,152 inactive）[11]，两者量级相差 3–4 个数量级，同一「率」在不同分母下不可直接相加。

（2）**aleatoric/epistemic 边界在数据稀疏时不可分**。需假设个体 SNP 引入的新位点确属「不可约随机性」，而非「尚未被测序覆盖」的 epistemic 缺口；当检测灵敏度本身受限时（结构变异检测不足）[11]，二者无法区分。

（3）**两域共享同一「proxy 效度」脆弱性**。0469 框架自身的局限（synthetic data 削弱真实复杂性、sample size 需功效分析、scoring 主观性须 LLM-as-judge 校准）[1] 在 CRISPR 侧对应存在（in vitro 不还原 in vivo off-target 模式）[13]，迁移使该脆弱性叠加而非抵消。

关键提示：本报告全部映射结论为「方法论/定义层面」的逻辑推断，非「数值层面」的实证等价。知识图谱中无任何边（violates / instantiates / implies）直接桥接 LLM 安全概念与 CRISPR 安全量。下游使用时应将置信度标注为「推断」，并在引用具体分值/阈值时附加来源论文与检测条件限定。

分析局限性

（一）**证据缺口**：知识图谱中缺失「LLM 作为主动风险预测器」这一侧的直接证据——被冻结的框架论文 0469 [1] 评估的是 LLM 自身安全性，而非用 LLM 预测第三方（CRISPR）风险，二者是不同任务；映射成立需要额外的中间假设（LLM 可作可靠风险预测器），KG 无直接支撑。

（二）**无验证性原始研究**：本分析的证据主要来自 2024–2026 年的综述与基准论文，尚无直接验证「LLM 安全度量在 CRISPR 上经验有效」的原始研究，迁移结论应标注为逻辑推断而非实证证明。

（三）**度量本体的差异**：ASR 分母是人为构造的攻击场景，而 off-target rate 分母是基因组搜索空间，两者量纲不可直接相加；此外 off-target 的「active」判据在数据集间不一致（Change-seq reads>100 vs GUIDE-seq 全标 active）[11]，迁移时必须显式携带评分函数。

（四）**共享的 proxy 效度脆弱性**：两域的度量都面临「proxy-of-proxy」问题——LLM 侧评分锚定在 automated labeler/LLM judge 上 [12]，CRISPR 侧 off-target 预测的「真值」由检测方法的灵敏度决定 [9]，两者都没有直接锚定到真实世界结局。

结论

本子问题的回答是：**五个 LLM 安全侧概念全部可映射到 CRISPR 安全评估的对应量，映射强度均为「强」，但迁移发生在结构与方法论层面而非数值层面**。ASR → off-target activity rate 属算子结构同构 [1][2][11]；Aleatoric/Epistemic 二分 → off-target 风险的可约简性分解（个体 SNP 不可约 vs 训练数据可约简）是全套中价值最高的一条，且与 0409 提出的汽车安全验证范式同构；Bootstrap 与 Δ-Method → off-target 基准指标的置信区间与敏感性分析 [6][7][11]；K-Bench「比较性而非普适阈值」告诫 → off-target 预测分数「比较性而非安全阈值」，可无损迁移 [8][9][12]。

对父问题 RQ5 的直接贡献：本分析表明，若要在 LLM 安全与 CRISPR 临床前安全评估之间建立「LLM-assisted risk prediction 交叉框架」，方法论迁移路径是清晰可行的（尤其是不确定性分解与统计推断方法），但需要补足三块拼图——(1) 一个可直接验证「LLM 输出的风险分数与真实 CRISPR off-target 结局相关」的实证研究；(2) 统一 off-target 的「active」判据与检测平台标准化；(3) 明确区分「LLM 自身安全性」与「用 LLM 预测风险」两个不同任务。在这些缺口被填补之前，任何把 LLM 安全度量直接当作 CRISPR 安全阈值使用的做法都应被视为证据不足。
