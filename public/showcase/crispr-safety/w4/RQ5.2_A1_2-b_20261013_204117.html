摘要

本报告针对子问题 RQ5.2——能否用 LLM 从序列/载体/剂量等输入预测脱靶与免疫风险，以及 KG 中是否存在任何跨聚类的 extends/compares_with/supports 边作为先例——进行了系统性的定义驱动推演与跨聚类边审计。核心结论是：**迁移方向在原理上可行且已有组件级先例，但知识图谱中不存在真正的跨聚类先例。** 所有 compares_with/extends 边均发生在同一聚类内部（脱靶预测工具之间、LLM 安全基准之间），没有任何一条边把 LLM 安全不确定性建模（[4]）与 CRISPR 脱靶/免疫预测连接起来。

序列→脱靶预测侧证据坚实：CRISOT [1] 在独立测试集上 PR-AUC 平均 0.46 并超越全部学习型与假设驱动方法（p<0.05），CCLMoff [2] 已直接用 RNA 预训练语言模型实现强跨数据集泛化，DNABERT-Epi [3] 相比从零训练 PR-AUC 提升 +0.1653（p<0.001）。载体/剂量→免疫风险侧则并行为结构式计算免疫学管线（NetMHCIIpan，[6]），而非 LLM。唯一的跨域架构先例是 CRISPR-LLM [7]——一个将 off-target prediction 列为 meta-task 的 LLM agent，但 KG 未记录其跨聚类边，属孤例。

研究背景与问题界定

RQ5.2 是父问题 RQ5 的子问题，追问一个交叉可行性判断：LLM 安全领域的不确定性建模与风险预测能力，能否迁移到 CRISPR 临床前安全评估。本子问题进一步收窄为两个可证伪的问题：(1) 能否用 LLM 从序列/载体/剂量等输入预测脱靶与免疫风险；(2) KG 中是否存在任何跨聚类的 extends/compares_with/supports 边作为先例。

本分析采用「定义驱动推演」视角：以 CRISOT/DNABERT-Epi 等脱靶预测的形式化/操作性定义作为公理，推演其约束被违反时所对应的问题类别，并审计这些类别之间是否存在 KG 记录的逻辑连接（对比、扩展、支持）。证据矩阵为冻结的 5 篇论文：[1] 0098、[2] 0101、[3] 0203、[4] 0477、[8] 0221。

论证主线一：序列→脱靶预测的 ML 基础坚实（强证据）

脱靶预测已是一个成熟的监督学习问题，这正是 LLM 迁移的算力基础。CRISOT [1] 用分子动力学派生 RNA-DNA 相互作用指纹，在独立测试集上 PR-AUC 平均 0.46，并超越四个假设驱动工具（KinPred/CRISPRoff/uCRISPR/CFD）与四个学习型工具（MOFF/CRISPRnet/DLcrispr/CNN_std），显著性 p<0.05。[2] CCLMoff 引入 RNAcentral 预训练 RNA 语言模型，在 13 种全基因组脱靶检测技术的数据集上展现强跨数据集泛化，模型解释还揭示了 seed region 的生物学重要性。[3] DNABERT-Epi 用两阶段微调（先错配位置预测、再二分类）的 DNA 基础模型，相比从零训练 PR-AUC 提升 +0.1653（p<0.001），加入表观遗传特征后 F1/MCC/PR-AUC 显著改进（p<0.001）。这三条证据共同表明：「预训练基础模型 + 序列输入 → 脱靶风险」范式已被实证，且 language-model 直接用于脱靶预测本身已有先例（[2]）。

说明：CCLMoff [2] 的原文未在检索段落中给出单一 PR-AUC 数值，仅有「在 13 种检测技术数据集上强跨数据集泛化」的定性结论，故图表中以 0 占位表示「无具体数值可提取」，不代表性能为零。CRISOT 0.46 为 in vitro/in cell 独立测试集的平均 PR-AUC。

论证主线二：载体/剂量→免疫风险有计算免疫学基础，但形态不同（中证据）

免疫风险侧存在并行的计算管线，但采用 MHC-I/II 结合亲和力的结构式建模而非 LLM。[6] 详述 NetMHCIIpan 4.0/4.2 等算法基于肽-HLA-II 结合亲和力与质谱洗脱配体数据训练，可将 107 个 mAb 有效分为高/低免疫原性，但明确指出现有免疫原性预测算法「依赖线性序列表位、忽略三级结构与翻译后修饰，对新型序列预测不精确」。[5] 指出脱靶效应与免疫原性受「CRISPR 效应蛋白持久性与活性」共同调控，限制作用时长可同时降低两者——这为「联合预测」提供机制依据。[5] 还报告商业 Cas9 蛋白来自 7 家厂商时内毒素水平不一，且免疫评估缺乏标准化协议。综合来看，「载体→免疫」预测在方法上存在，但输入是蛋白序列/表位，而非 LLM 直接理解「载体类型+剂量」组合——后者在 KG 中无任何直接证据。

论证主线三：LLM 安全不确定性建模的接口存在，但从未被接到 CRISPR（关键缺口）

LLM 安全侧已发展出可直接被迁移的形式化接口。[4] 对 210 个安全基准的综述确立了 Probabilistic Risk Assessment（PRA）框架——风险 = 违规概率 × 后果严重度——并暴露三大结构性缺陷：81%（N=170）基准只评测「已知已知」、79%（N=166）把经验频率当作概率而无置信区间、缺乏分布漂移鲁棒性。这与 CRISPR 侧的核心痛点高度同构：脱靶预测同样面临约 97% 类别不平衡（[11] 因此弃用 AUROC 改用 AUPR）、跨数据集泛化不足（[10]）、以及 [6] 指出的免疫原性模型不精确问题。

然而，KG 中断言这一迁跃的 extends/supports 边并不存在。[4] 的出边 extends 仅指向 [14] 0484、[15] 0509、[16] 0522 三篇 LLM 安全论文，全部停留在 AI 安全簇内。因此「LLM 安全不确定性建模 → CRISPR」目前仅为类比推论（类比而非演绎），推演强度应降级为 weak。

论证主线四：唯一的跨域锚点——CRISPR-LLM 孤例

跨域桥接的唯一实质先例是 CRISPR-LLM [7]。它是一个 LLM-powered 设计与规划 agent，明确将「Prediction of Off-target Effects」列为 6 大核心 meta-task 之一，并设有专门的 Off-target Prediction Mode，同时集成 gRNA 设计工具（Broad Institute gold-standard 库、CRISPRPick）与外部工具集。这在方法层面直接示范了「LLM agent 编排 + 领域预测器」的架构——即 RQ5.2 所设想的交叉框架的雏形。

但 [7] 在 KG 中既无 extends/supports 出边连向任何脱靶预测工具（如 CRISOT/CCLMoff），也无相关入边，故只能作为孤例（weak evidence）。其局限还包括：current agent 无法从自然语言生成完整载体/构建体，这恰好命中 RQ5.2 中「从载体输入预测」这一环的能力空白。

分析局限性

1. **跨聚类先例的结论为「不存在」，而非「不可能」**：KG 边可能不完整，审计结果只能说明「未被记录」，不能排除未发表的实际迁移工作。故 C1 的穷尽性受限于 KG 覆盖率。

2. **免疫风险侧证据稀疏**：KG 中载体/剂量→免疫的 LLM 化证据与不确定性量化实证几乎为空，C5、C9 的置信度仅为 medium；模型只能证明「结构式管线存在」，无法评估 LLM 迁移的实际性能。

3. **形式化定义强度参差**：CRISOT/DNABERT-Epi 给出的更多是操作性定义（方法如何计算）而非公理化定义（∀/∃ 量词的完备约束），因此本报告的「定义驱动推演」在脱靶侧是操作约束违反的映射，在 LLM 安全侧（PRA）才是较强形式化的框架，两侧推演效力不对等。

4. **存在性偏倚**：证据矩阵论文以「正面结果」为主（方法优于基线），负面结果与失败案例（如跨物种泛化失败）在 KG 中记录不足，可能高估迁移可行性。

结论

回答 RQ5.2：**用 LLM 从序列/载体/剂量输入预测脱靶与免疫风险在原理上可行，但 KG 中不存在系统性的跨聚类先例。** 序列→脱靶预测已有成熟的 ML/预训练模型基础（[1][2][3]），载体→免疫有结构式计算免疫学基础（[6]），LLM 安全侧已提供可迁移的风险量化接口（[4]）。唯一的跨域架构锚点是 CRISPR-LLM [7] 的孤例，而连接 LLM 安全簇与 CRISPR 预测簇的 extends/compares_with/supports 边为零。

因此，该交叉框架需由研究者从零搭建，其最薄弱环节是：(a) 免疫风险的 LLM 化——目前无一篇论文用 LLM 从载体/剂量组合预测免疫原性；(b) 不确定性量化——LC 侧的 PRA/校准思想尚未在 CRISPR 风险预测中落地；(c) 联合建模——脱靶与免疫仅在「效应蛋白持久性」这一机制维度上被文献连接。建议未来工作以 CRISPR-LLM 为架构模板，将 CRISOT/CCLMoff/DNABERT-Epi 作为可调用预测器，并显式引入校准与置信区间评估，以填补 KG 中观测到的跨聚类连接空白。
