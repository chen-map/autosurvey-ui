摘要

本报告以「定义驱动推演」为核心方法，回答 RQ5.3：如何区分并传播 CRISPR 安全评估中的 aleatoric 与 epistemic uncertainty，并给出阈值校准方案以支撑监管沟通。分析以四篇冻结证据论文（0455 两阶段骨科风险模型、0432 金融 expectile 风险框架、0543 机器人校准预测安全、0381 加权 Brier 分数）承载的「不确定性处理管线」为公理基础，辅以 0552、0409、0440、0371、0173、0233 等桥接论文，从定义出发演绎问题关系。

核心结论：aleatoric/epistemic 的区分在证据矩阵中已有形式化界定（0552、0409），但全部来自非 CRISPR 域，属类比迁移；0455 提供了基于 bootstrap 离散度的不确定性 z-score 传播机制；0381 提供了把不可约分量（UNC）与可修分量（MCB/DSC）分账的数学分解；0543 提供了校准三件套（温度缩放、方差估计、保形预测）与「学习模型只排序、保证来自确定性 shield」的架构分离原则。综合而言，方法论骨架可迁移（answered），但阈值与划分的数值标定尚未在 CRISPR 域内验证（partial）。

核心分析一：从定义演绎不确定性双通道

以「aleatoric = 数据生成过程的内在随机变异（不可约）」「epistemic = 模型知识不足（可约）」为公理 [5][6]，可从定义出发推出：任何安全评估的总不确定性必须被拆成两个通道分别处置。0409 给出了同构界分——轮径估计的 epistemic 不确定性「会随测量不断降低」，而行人闯入车道与制动失效属「天然不可预测的随机事件」[6]。将这一公理代入 CRISPR 语境：off-target 编辑率的细胞/个体/染色质依赖可变性属 aleatoric，而未见序列预测失败属 epistemic。0440 明确记载 Cancellieri 等的发现——自然 SNP 可「创造新的 off-target 位点或消除原有位点」，同一条 sgRNA 在某个体完全安全而在另一体的 SNP 背景下成为近乎匹配的隐患，因此需要「按患者或多族群评估，而非假设 one-guide-fits-all」[7]。这一「不可通过更多测序消除的个体特异性可变性」即为 aleatoric 通道的 CRISPR 载体。

核心分析二：传播机制——z-score 与检测升级路径

0455 提供了直接可迁移的传播机制：用 50 个 bootstrap 模型预测概率的离散度构造不确定性 z-score，z = |P̂ − threshold| / σ_boot，以 z = 2（预测概率落在最优阈值两个标准差内）判为「不确定」，并将不确定病例下传至引入 DXA 影像特征的第二集成再评估 [1]。在 MrOS 队列约 61.5–62.3%、SOF 队列约 74.5–75.2% 个体于 Stage 1 被高置信分类，其余进入 Stage 2 [1]。映射到 CRISPR，这套机制对应「低置信 off-target 预测自动触发正交实验检测」的升级路径——因为 CRISPR 领域的 off-target 图像「随检测方法灵敏度提升而不断变清晰」，DISCOVER-Seq+ 可将灵敏度提升约 5 倍并发现早先被漏掉的位点 [7]。这恰是 epistemic 不确定性被主动缩减的实例，而 aleatoric 部分则应作为残余风险陈述。

核心分析三：阈值校准方案

0381 提供了把 aleatoric 分量与可修分量分账的理论工具：加权 Brier 分数可精确分解为 EX,Y[BSw] = MCBw − DSCw + UNCw，其中 UNCw = ℓw(π,π) 度量「预测二值结果的固有难度」，即 aleatoric 部分；MCB 为失校准、DSC 为判别力 [4]。阈值选择上，0381 用决策论框架把最优 cutoff c 与代价比 C0/(C1+C0) 绑定，导出 opt-in net benefit NB(c) = TPR(c)π − [c/(1−c)]FPR(c)(1−π) [4]。在 CRISPR 中，若漏检一例高危 off-target 的代价远大于一次假阳性的额外验证成本，则该代价比自然把阈值推向高敏感端。0543 给出校准工程三件套：温度缩放（不改排序、廉价）、ensemble/MC-dropout 预测方差、以及保形预测包装——把单点风险概率转为在用户指定 miscoverage α 下、仅依赖数据可交换性的集合值决策，使阈值带有分布无关的有限样本覆盖保证而非手调常数 [3]。其决定性证据是校准消融：去掉校准损失后 AUROC（0.87 vs 0.88）与 Brier（0.09 vs 0.08）几乎不变，但 ECE 劣化约 3.5 倍（0.14 vs 0.04）[3]，证明判别力与校准可分离。

核心分析四：迁移到 CRISPR 与监管沟通

0543 的架构分离原则——学习模型只做「对候选的校准排序」，一切保证由确定性 safety shield 与 fallback ladder 产生，学习预测「从不扩大可接受动作集」[3]——为 CRISPR 提供监管沟通范本：LLM/ML 只负责优先化候选 sgRNA 与 off-target 位点，安全保证必须来自确定性正交实验检测与保守 fallback。这与 CRISPR 既有监管实践一致——FDA/EMA 要求用多种正交方法（in silico + 细胞实验 + 无偏测序）刻画 off-target 谱，exa-cel 在回输前完成全基因组 off-target 映射 [7]。CRISPR-LLM 表明 LLM 已能作为 agentic 层整合领域知识、检索与外部工具规划基因编辑实验并给出逐步协议与验证策略 [9]，为「LLM-assisted risk prediction」交叉框架提供现成接口。

关键警示：四篇冻结证据论文全部来自非 CRISPR 域，其对 CRISPR 的适用性属类比迁移而非同域验证。CRISPR 特有的 aleatoric 源（mosaicism、个体 SNP 特异性、染色质状态）在证据矩阵中缺乏量化数据，「CRISPR 中的 aleatoric/epistemic 划分」目前是逻辑推断（weak）而非同域实证。

分歧点与对抗性检验

分歧点一——保证责任的承担主体。0543 明确在学习建模域中「JEPA 世界模型不提供任何保证」，保证全部来自确定性 shield [3]；但 CRISPR 中「确定性 shield」只能是实验检测本身，而检测存在灵敏度上限（CHANGE-seq/GUIDE-seq 在高维 inactive 位点上 AUPR 波动大、precision 可低至 0.07–0.5 [8]），故保证强度弱于机器人域。

分歧点二——阈值校准的多目标性。0432 自陈「阈值确定过程保留主观成分，替代阈值选择方法应被探索」[2]；0543 同样自陈「保守性有代价——激进拒绝降低碰撞却提高卡死与干预率，无设置能同时优化所有指标」[3]。即阈值校准本质是多目标的，不存在单一最优，这与 0381 net benefit 是 cutoff 函数、指定固定 c 反映恒定代价比常不成立的观察一致 [4]。

分歧点三——small-sample 是共同瓶颈。0432 用 Bayesian 先验 + MCMC 应对小样本尾部估计 [2]，0455 用 bootstrap 不确定性 [1]，而 CRISPR 早期试验「招募患者少，阻碍了对安全性的结论性评估」（KG limitation 节点），使 epistemic 通道在临床前阶段尤其大。

分析局限性

其一，域外迁移风险：四篇冻结证据论文全部来自非 CRISPR 域，其术语、区分机制与阈值方法可迁移但缺乏 CRISPR 域内量化验证。其二，aleatoric 划分缺乏量化：CRISPR 特有的 mosaicism、个体 SNP 特异性、染色质状态在证据矩阵中无量化不确定性度量，0440 承认 AI 预测「需要按患者评估」但未给出可校准的不确定性度量 [7]。其三，保形预测假设脆弱：0543 的保形保证依赖数据可交换性 [3]，而 CRISPR 个体间基因组异质性与分布漂移可能违反该假设。其四，CRISPR-LLM 未报告不确定性或阈值输出 [9]，无法直接充当阈值校准层。综合，框架的方法论骨架可迁移（answered），但阈值与划分的数值标定尚未在 CRISPR 域内验证（partial）。

结论

RQ5.3 的答案是肯定的但附条件：可以形成一个可操作的三层交叉框架——(1) 以 aleatoric/epistemic 双通道区分为公理，把 CRISPR 安全评估的不确定性拆成「不可约残差」与「可缩减误差」；(2) 以 bootstrap z-score（0455）、Brier 分解（0381）、校准三件套与保形预测（0543）作为传播与阈值校准工具；(3) 以「学习模型只排序、保证来自确定性正交检测」的架构分离原则驱动监管沟通。但四篇证据论文全部来自域外，CRISPR 特有的 aleatoric 源缺量化证据，故本框架应标注为「方法论骨架达成、数值标定待同域验证」——即 partial。后续工作应优先在 CRISPR 域内建立 aleatoric/epistemic 的量化划分标准，并验证保形预测在基因组异质性下的可交换性假设。
