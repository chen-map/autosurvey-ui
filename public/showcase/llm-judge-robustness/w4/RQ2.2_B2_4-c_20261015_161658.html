摘要

本研究对 RQ2.2（上下文长度限制、信息遗忘及检索上下文依赖性对 LLM Judge 判定一致性的影响机制）进行了系统性分析。分析发现，上下文长度限制和检索上下文依赖性是影响 LLM Judge 判定一致性的两个核心范式级挑战。上下文长度限制导致 LLM Judge 无法充分利用 few-shot judging 提供的指导，降低跨实例判断一致性；检索上下文依赖性则导致 LLM Judge 在无参考情况下表现出强烈的 over-crediting 倾向，当参考答案被交换或替换时，其准确性平均下降 30-40%。信息遗忘与检索依赖性相互强化，进一步损害判断可靠性。多代理辩论框架会加剧这些模式，导致代理之间的判断不一致。从假设溯源分析来看，这两个问题均违反了 LLM Judge 的硬性前提假设，当前没有方法成功松弛这些假设，表明这是当前技术范式的系统性天花板。

结论

本研究系统分析了 RQ2.2 的核心挑战，得出以下结论：

1. 上下文长度限制和检索上下文依赖性是影响 LLM Judge 判定一致性的两个核心范式级挑战，两者均违反了 LLM Judge 的硬性前提假设。从 KG 的 assumption 节点分析来看，当前没有方法有 relaxes 边指向这些假设，表明它们是当前技术范式的系统性天花板。

2. 上下文长度限制导致 LLM Judge 无法充分利用 few-shot judging 提供的指导，降低跨实例判断一致性。多代理辩论框架会加剧这种模式，通过 agent 之间的信息传递受到上下文长度的限制，导致早期信息的相关性和权重逐渐降低，引发判断不一致。

3. 检索上下文依赖性导致 LLM Judge 在无参考情况下表现出强烈的 over-crediting 倾向，当参考答案被交换或替换时，其准确性平均下降 30-40%。这表明 LLM Judge 无法可靠地将判断建立在提供的参考上，而是倾向于使用自身的先验知识。

4. 信息遗忘与检索上下文依赖性相互强化，进一步损害判断可靠性。随着上下文长度的增加，LLM Judge 会逐渐遗忘早期输入的信息，导致在复杂评估场景中判断不一致。

5. 范式级缺陷的客观判据是：某个被所有受影响方法共同 requires 的 assumption 节点没有任何 relaxes 边。从 KG 的结构化数据来看，上下文长度限制和检索上下文依赖性均满足这一判据，表明它们是当前技术路线的理论天花板。

6. 突破天花板需要范式变革，例如开发基于检索增强的确定性评估框架、引入人类监督的混合评估模式，或探索非概率评估范式（如基于形式验证的评估方法）。
