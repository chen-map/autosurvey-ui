摘要

本报告针对 RQ1.1“现有工作中『进化（evolution / self-improvement）』被赋予哪些不同含义，其概念边界如何界定？”进行系统性分析。核心结论是：现有文献中的“进化/自我改进”并非单一概念，而是一个被至少五种不可通约含义共享的伞形词。我们将其可操作的概念边界归结为两个正交判据的乘积：(A) 进化所改写的载体——是基座模型参数，还是模型之外的脚手架/持久状态；(B) 改进是否作为跨任务的持久提交——而非仅在单次任务内通过重试再答完成即时纠正。

六篇证据矩阵论文恰好落在“进化”含义谱系的不同位点上：[0014] 代表最弱含义的回合内反思纠正，[2281] 与 [2202] 代表跨任务的脚手架内持久进化，[2256] 代表训练无关的闭环自改进，而 [0850] 与 [0933] 则属于共享“随时间演化”表层语义、但不涉及智能体自身轨迹驱动的邻近用法，应被显式排除。文献中存在明确的分片化批评（[2368] 指术语与范围碎片化，[2200] 承认概念边界仍在协商），支撑了重构的必要性。

研究问题与分析方法

本子问题聚焦于辨析“进化”一词在 LLM 智能体文献中的多义性及其概念边界。分析方法遵循“提取现有分类体系 → 操作化诊断其缺陷（重叠/遗漏/模糊边界）→ 推导正交重构维度 → 验证覆盖与互斥 → 对抗性检验”的流程，但所有信息均通过知识图谱（KG）的结构化节点与边、以及论文原文段落检索获得，而非依赖外部文件。

具体地，我们先从 KG 中加载 paper / problem / limitation / assumption / method / dataset / metric 七类节点，再对六篇证据论文逐一获取其 proposes/addresses/evaluated_on/measured_by/has_limitation 关系边，最后用语义检索工具精读约 16 篇综述与定位论文的定义章节，以确认不同作者对“self-evolving”与“self-improving”的界定方式。

核心分析：正交重构维度与矩阵

基于对 Problem 节点描述与各论文定义字段的归纳，我们提炼出两个满足穷尽性与互斥性的正交维度。维度 A（进化载体）取自 [2368] 的“foundation model improvement vs scaffold improvement”二分，以及 [0038] 的四元载体坐标（Θ_t 模型参数 / M_t 记忆 / T_t 工具 / W_t 工作流）；维度 B（持续性）取自 [2368] 的形式化——自诱导算子 U 必须“提交持久变更”，而非 X_t 的瞬时演化；[2200] 的“static / short-horizon / long-horizon”评估分层亦可印证该维度。

在此基础上增加一道准入规则：更新必须由智能体自身轨迹或反馈驱动。该规则用于排除 [0850] 的分布时间演化与 [0933] 的数字孪生版本演化——二者虽含“evolution”字样，但不满足“智能体—自身轨迹”的因果链。经此三维约束，六篇证据论文均获得唯一归属或明确的排除理由，矩阵中不存在无法判定的孤儿节点。

值得强调的是，这一重构的价值在于它把此前分散于不同综述的两种“两分法”（[2368] 的模式二分与 [0038] 的载体坐标）统一为一套可判定的准入规则，从而使“什么算进化、什么只是即时纠正、什么根本无关”成为可由判据机械执行的操作。

概念边界的四道判定关卡

综合文献，可将“什么是严格意义上的自我进化”整理为依次通过的四道关卡，任何一道不通过即落入不同含义层或直接被排除。

第一关（是否存在持久载体）：改进是否被写入某种可复用的持久状态？[0014] 的反思文本只注入当次再答提示、任务结束即消失，故止步于此关，属于“即时纠正”而非进化。第二关（载体类型）：持久状态是模型参数还是外部脚手架？这一关区分了 [2368] 的两条路径，也解释了为何 [2][3][4] 均可在冻结参数下实现进化。第三关（持续性跨度）：改进是否跨任务/跨回合被提交并复用？[4] 的 Episode 2 复用第一回合经验库后 VQAScore 由 0.852 升至 0.884，是其跨任务性的直接量化证据。第四关（驱动来源）：更新是否由智能体自身轨迹驱动？这是排除 [5] 与 [6] 的关键——它们虽有“evolution”之名，却与智能体的自我更新无关。

该四关框架同时也解释了术语混乱的根源：不同作者往往只强调其中一关（如 [2205] 强调“闭合部署—改进环路”，[0038] 强调“可复用状态”），而缺乏统一的四关判据，导致同一机制被贴上不同标签。

文献对现有分类的批评证据

重构动机有明确的文献支撑，而不仅出自我们的推断。[2368] 直言“the broader research landscape remains highly fragmented in both terminology and scope”，并指出 self-correction、meta-prompting、self-play 等相近思想“常以不同标签出现，掩盖了底层机制的相似性”。[2200] 承认该研究领域“conceptual boundaries are still being actively negotiated”，因而刻意以“引导性综合”而非刚性边界来组织综述。[0038] 则批评传统基于组件或攻击类别的分类“can fragment what is in fact one causal incident”，主张以“载体×操作”的转移为最小比较单元。

这些批评共同指向同一病灶：既有的“按组件/按标签”分类既不互斥（同一机制可落入多类），也不穷尽（新兴机制无法归位），并且容易把语义相近但本体不同的现象（如非智能体的“evolution”）错误卷入。我们的正交重构正是针对这三点的直接回应。

对抗性验证：新体系是否真正消除了旧缺陷

我们逐一比对新体系是否实质解决了旧缺陷。对于“术语碎片化”缺陷：在新矩阵中，[2][3][4] 三种被不同标签描述的机制（经验反思学习、元工具学习、闭环自改进）均落入同一格（脚手架×跨任务），且其共性被显式刻画为“持久脚手架状态的跨任务复用”，说明相似机制不再被标签割裂。

对于“概念溢出”缺陷：新体系通过第四道关卡把 [5] 与 [6] 显式判为 N/A，并给出可复核理由（非智能体轨迹驱动），从而不再让非智能体的“evolution”稀释“自进化”的内涵。

但仍需诚实指出未完全解决之处。其一，[4] 的 Episode 2 是否构成真正跨部署的持续进化存在争议——若经验库不跨部署复用，其跨任务性弱于 [2][3]。其二，[2] 自身报告迭代式 ERL 源任务成功率更高但测试泛化反而下降 5.4%，说明“经验累积”未必等于“进化”，新体系目前只能标注该现象，尚无法用维度自动判别“有效进化 vs 无效累积”。其三，也是最重要的——新体系在“参数内进化”格上几乎为空，因为六篇证据论文无一提供参数更新的正面量化实例。

分析局限性

本报告的主要局限在于证据覆盖的不对称。六篇证据矩阵论文几乎全部集中在“脚手架内进化”一侧：四篇提供了可核验的量化增益（[1] p<0.001 的显著提升、[2] +7.8%、[3] GAIA 22.3→47.6、[4] VQAScore 0.789→0.884），而“参数内进化”这一维度在证据矩阵内没有任何正面实例，仅由 [7][8] 的“固定参数、只改技能文件”设定间接反衬。因此，本报告对完整含义谱系的刻画在参数内一维上覆盖不足，相关判断（例如“参数内进化可能带来安全对齐退化”）多为文献综述层面的推断而非证据矩阵内的直接验证。

其次，术语本身尚未统一：“self-evolving”与“self-improving”在文献中长期混用。本报告建议以“self-evolving”作为伞概念，但这一选择属于约定而非领域共识。此外，持续性维度缺少可量化的最小持续阈值，目前只能做定性二分（回合内 vs 跨任务），无法对“轻度持久”与“强持久”作更细的区分。最后，[5] 与 [6] 被排除的理由是“非智能体轨迹驱动”，这是基于本体语义的判断；若未来出现把分布演化或孪生版本演化与智能体更新耦合的工作，则这一排除边界需要重新审视。综合而言，本报告结论的置信度约为 0.84。

结论

RQ1.1 的答案是：现有工作中的“进化/自我改进”是一个多义伞形词，至少包含五种含义——(1) 可复用状态的持久改写（主流定义，[0038][2368]）；(2) 回合内反思—再答的即时纠正（[1]）；(3) 反思生成可迁移启发式的跨任务积累（[2]）；(4) 零参数更新的工具/知识元学习（[3]）；(5) 训练无关的轨迹经验闭环自改进（[4]）；此外还有必须排除的邻近用法——非智能体的分布时间演化（[5]）与数字孪生版本演化（[6]）。

其概念边界可用“载体（参数内 vs 脚手架内）× 持续性（回合内纠正 vs 跨任务提交）”两个正交判据界定，并辅以“更新须由智能体自身轨迹驱动”的准入关。该矩阵使六篇证据论文各自获得唯一归属或明确排除理由，并统一了此前分散于不同综述的两种两分法。

最重要的启示对父问题 RQ1 有直接价值：若要用统一的“进化轨迹”概念框架刻画 LLM 智能体的持续变化，则“轨迹”不能仅指交互序列，而必须指持久载体状态随时间的被改写过程——这正是本报告二维矩阵中“跨任务持久提交”一列所刻画的对象。当前证据的最大缺口在于参数内进化缺少正面量化实例、以及缺少能量化“持续程度”的阈值，这应成为后续工作优先补齐的方向。
