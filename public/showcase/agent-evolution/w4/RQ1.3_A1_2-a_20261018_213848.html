摘要

本报告针对 RQ1.3 回答：经验存储层（memory update）与策略更新层（policy optimization）应如何区分，以及二者边界模糊导致哪些可复现性问题（如 Agent amnesia、skill forgetting）。核心结论是：边界不应按"更新发生在何处"划分，而应按两个正交属性联合划分——(A) 被更新对象是"内容/陈述性经验"还是"控制/程序性行为"；(B) 更新载体是"外部化非参数写回"还是"内化参数化改写"。这一重构在文献中有明确术语锚点（2274 区分 what is known vs. what to do）[1]，也能无歧义安置四类问题。

边界模糊不是语义细节，而是可复现性问题的直接生产源。文献已承认记忆与策略是两层（EvoTest 将 baseline 切为 memory-based / reflection / prompt-optimization / weight-update 四类）[2][3]，但同一系统又把 memory updates 与 guiding prompt 放入同一次整体改写，造成"名义分层、操作耦合"。这种耦合使失效无法归因、无法隔离、无法快照复现，具体表现为 Agent amnesia[1]、capability erosion / skill forgetting[4]、library drift 与 blind curator 隐蔽失效[5]、以及 instruction drift / 记忆污染[6]。

本分析基于知识图谱（KG）六类节点与关系边，结合 132 篇论文原文段落的语义检索完成。查询覆盖的实体类型包括：problem（629 条）、method（558 条）、limitation（317 条）、assumption（200 条）、metric（391 条）、dataset（400 条）。通过 get_candidate_entity、get_relation、search_paper_sections 对证据矩阵中全部 6 篇冻结论文（2274、2402、2283、2230、2272、2467）及 6 篇直接关联文献（2291、2244、2429、2361、2306、2289）进行了精读，共调用工具 42 次。核心量化证据（AUC、retention gap、模板编辑质量、false-pass 阈值）均来自论文原文段落，可在 references 中逐条溯源。

现有分类体系的缺陷诊断

对现有分层体系的 MECE 检验揭示三类缺陷。

第一类是重叠（overlap）：EvoTest 与 2467 在概念上把 memory-based 定义为"不修改核心策略提示或决策逻辑"，但在其 Evolver 主提示中，"memory updates（成功/失败数据库）"与"guiding prompt（高层策略）"作为并列四项被同一次整体改写生成[3]。同一段轨迹、同一次写回同时改动两类对象，使二者在操作层面无法区分。

第二类是遗漏（omission）：现有框架"只测新任务前向进展，从不问旧能力是否保留"[4]，因此 memory 与 policy 的相互侵吞在评测中被系统性遗漏。

第三类是模糊边界（ambiguity）：library drift 的治理失效"在聚合指标上不可见"[5]，说明层间边界处存在无任何指标覆盖的盲区。诊断来源为 literature_acknowledged 与 empirical_observation 的混合。

边界模糊导致的可复现性失效

四类失效均有量化证据。

Agent amnesia：2274 定义为 LLM 无状态、缺乏从执行经验系统学习的机制[1]。若系统没有独立可检查的记忆写回，每次会话从零开始，评测只反映 backbone 波动，无法复现"学会了什么"。

Capability erosion / skill forgetting：2306 发现 self-evolution 非单调，在 workflow、skill、model、memory 四通道同时侵蚀旧能力[4]。无约束记忆更新使旧域平均性能从 83.9% 降至 81.6%，CPE 正则化后回升至 83.3%，retention gap 从 2.3% 降至 0.7%。当记忆层与策略层边界不清时，掉点来源（记忆被驱逐 vs 策略漂移）无法判定。

Library drift / blind curator：2361 证明 skill library 漂移可使性能跌破 no-skill 基线，而退役保障依赖"判定信号诚实"的隐含假设；LLM judge 的 false-pass 偏差超过阈值 (1−τ)/2（如 0.45）后，退役机制失效且"再多数据也救不回来"[5]。该失效在聚合指标上不可见，是最危险的可复现性问题。

Instruction drift / 记忆污染：SSE-Bio 用细粒度模板编辑对比粗粒度重写，显著降低更新越界[6]。2429/2289 进一步指出未管理记忆会变成 context bloat 反而损害准确率[8][7]。

正交重构：新的二维分类体系

提出两个正交维度以覆盖全部相关 problem 且互斥。

维度 A（作用对象）：content（陈述性经验内容，what is known）vs. control（程序性控制行为，what to do）。该术语锚点来自 2274 对陈述性知识与程序性/经验性知识的明确区分[1]。

维度 B（载体机制）：externalized_nonparametric（外部化非参数写回）vs. internalized_parametric（内化参数化改写）。该维度来自 MEMRL 冻结 LLM 权重、仅在 episodic memory 上做非参数 RL 的显式解耦[9]，以及 SSE-Bio 只训练 Proxy、固定 Manager/Dev/Critic 的分工[6]。

二维交叉形成四象限，可将记忆污染/遗忘、library drift、参数化灾难性遗忘、策略漂移/安全回归四类问题无歧义安置，且对相关 problem 节点实现高覆盖率与互斥归置。唯一不稳定格是 procedural memory（技能/工作流）——2289 将其作为与 memory 并列的外部化维度[7]，而 2274/MemRL 视其为记忆的一种[1][9]。

可行的分层操作范式

MEMRL 给出最干净的分层范式：冻结 LLM 权重、只在 episodic memory 上做非参数 RL，用 Q 值区分"功能效用"与"语义相似"滤除噪声，从而在不动参数的前提下实现"稳定推理 + 可塑记忆"[9]。SSE-Bio 只训练检索 Proxy（策略）、固定其余组件，并以细粒度模板编辑约束记忆演化[6]。2429 进一步把记忆建模为 middleware，要求 episodic/semantic/procedural 分 namespace 存放，并配套 admission / forgetting / eviction 治理[8]。这些实践共同说明：分层不仅可行，而且分层协调（而非整体重写）是降低可复现性风险的方向。

分析局限性

本分析存在三点证据缺口与不确定性。其一，尚无统一的可复现性基准能分别快照 memory 与 policy 状态并做交叉消融——2306 最接近但只覆盖四通道、未做层间交叉隔离。其二，blind curator 的阈值结论来自单一报告写作域加一个代码交叉验证，跨域泛化未验证[5]。其三，2272 的 hindsight credit assignment 只优化步级优势（策略层细粒度），未讨论其写回是否进入记忆，属未覆盖接口。此外，procedural memory 的层归属在文献中存在实质分歧（2289 视为与 memory 并列维度[7]，2274/MemRL 视为记忆子类[1][9]），因此正交重构 C10 标注为受文献内部分歧约束的开放点。

结论

经验存储层与策略更新层的最本质区分是一组正交维度：作用对象（content vs. control）× 载体机制（外部化非参数 vs. 内化参数）。这一划分有文献术语锚点[1][6][9]，能覆盖并互斥归置记忆污染/遗忘、library drift、参数化灾难性遗忘、策略漂移/安全回归四类问题。边界模糊之所以生产可复现性问题，根源在于主流系统"名义分层、操作耦合"——同一轨迹、同一 judge、同一次写回同时改动两类对象，使失效无法归因、无法隔离、无法快照。四类失效（Agent amnesia[1]、capability erosion/skill forgetting[4]、library drift/blind curator[5]、instruction drift/记忆污染[6]）均有量化证据：旧域性能 83.9%→81.6%、retention gap 2.3%→0.7%、false-pass 阈值 0.45、模板改动 3.28→1.46。可行的方向是显式分层协调（冻结+非参数化记忆 RL[9]、只训策略 Proxy[6]、memory-as-middleware 治理[8]），而非整体重写。对 RQ1.3 定性为 answered，但 procedural memory 的层归属与统一层间快照基准仍为开放问题。
