摘要

本报告回答子问题 RQ2.2：工具使用与工作流机制如何作为"外化进化载体"改变智能体的能力边界，其进化信号来自何处。基于知识图谱（KG）中六篇冻结证据论文及 4 篇互为佐证的综述/方法论文，我们提出一个五层外化进化栈模型：L1 工具/环境反馈层、L2 工具接口契约层、L3 工作流编排层、L4 检索增强层、L5 外化工件层（技能文件）。

核心结论是：工具与工作流的本质是"把原本要写进模型参数的适应压力，转移到一个可读写、可审计、跨轮次复用的外部结构上"，从而在不改动底座权重的前提下扩展能力边界。其进化信号来自三条来源——(1) 工具反馈（确定性求解器/API 返回值），(2) 工作流复用（技能文件、动态数据流 schema、两层接口沉淀），(3) 检索增强（RAG 把大库压缩为可注入元数据）。三者都表现出"有界收敛"而非无限自进化，且同时构成系统性安全风险源。

进化信号的三条来源：工具反馈 / 工作流复用 / 检索增强

**信号源一：工具/环境确定性反馈。** [1] 的技能进化是 solver-grounded 的——meta-agent 依据每任务记录（执行错误、逐准则反馈、CPF、BM、SG、尝试次数）改写技能文件，信号来自确定性物理求解器。这带来可量化的有界增益：same-type 成功率 SG 从 38%→74%，CPF 0.51→0.87，平均尝试次数 4.10→2.30。但在 New-type-A（测试族完全未在训练/验证出现）上，进化只维持而非创造能力（SG 稳定约 90%），说明工具反馈信号只在覆盖的族类内有效。[4] 的 6G 编排以约 200 个 API 的工具库 + 语义向量检索 + 两阶段训练，在工具反馈闭环中校准"规划步骤→API 调用"，参数从任务描述、前序输出、默认值三处自动绑定。[3] 的 GLM4-plus 在 100 个 BIM 任务上达 90% 完成率、99% 准确率，但准确率随难度 Level-1→Level-3 骤降——工具反馈驱动的能力边界随交互链长收缩。

**信号源二：工作流复用。** [2] 采用运行时渐进推断的动态数据流 schema 作为外化载体：无需预定义，从现场溯源流增量推断"任务间数据如何流动、捕获哪些参数与输出、工作流如何演化"，并在 RAG 管线中复用。关键设计是 operates on metadata rather than task provenance data，使 LLM 性能与工作流规模解耦——在 Frontier 超算化学工作流上正确或部分正确回答超过 80% 查询，并从简单合成工作流零额外领域工程迁移成功。被复用的是抽象出的结构（schema）而非具体任务数据。[7] 的符号学习把 pipeline 本身当作可优化符号组件，用语言损失/梯度/优化器联合优化 prompts、tools、pipeline，证明工作流结构可被反馈驱动、可迁移。

**信号源三：检索增强。** [4] 因"上千 API 无法全部塞进 prompt"而提出 API 指令语义向量化 + GCS 相似度检索，把工具选择转化为检索问题；[2] 的 RAG 采用元数据/部分数据/全数据三档策略注入上下文，并明确 RAG 策略与领域值驱动大部分增益。检索增强把外部大状态压缩成可注入上下文，从而扩展边界而不触发上下文溢出——一种"外化但受控"的信号。

跨层传播与风险结构：外化载体同时是放大器

工具与工作流机制在扩展能力边界的同时，构成了结构性的风险放大层。[6] 显示工具集成 Agent 面临 DPI、IPI、MP、backdoor 四类注入攻击，一条恶意工具即可劫持整个工作流，其 ATF（异常检测过滤工具）/NTR（恢复良性工具集）依赖工具描述的语义异常检测来防御，但作者明确承认未在动态环境中评估——工具生态越外化、越动态，防御越难闭环。[5] 在 1072 个可执行多轮场景、2144 个 episode 上测得 12 个 LLM Agent 平均 ASR 达 47.1%，多个模型超 70%；其中 Long-Horizon Instability 风险随交互预算从 4 轮增至 10 轮由 62.9% 升至 80.0%，说明工具反馈/工作流层的不安全行为随链路累积而放大。

[8] 的综述为这种跨层传播提供形式化语言：工具/工作流状态变化被建模为动态图边重写（LINK/UNLINK/REWIRE），并指出"工具演化可触发依赖技能与工作流的重验证"，即局部工具契约变更会沿依赖边级联影响上层工作流——这正是"外化载体的风险向上层传播"机制。但该综述亦承认，现有方法"rarely expose the actual cascade trace"，级联追踪缺乏实证，因此这一传播链在 KG 中多为"inferred_no_direct_support"性质。

结论

工具使用与工作流机制作为"外化进化载体"，通过把适应对象从模型权重转移为可读写、可审计、可迁移的外部结构，实质性地扩展了智能体的能力边界。其进化信号来自三条互补来源：工具/环境的确定性反馈（[1][3][4]，产生可量化的族内有界增益）、工作流复用（[2][7]，把抽象结构沉淀为可迁移载体）、检索增强（[2][4]，把大状态压缩为可注入上下文）。

然而能力扩张是"有界的"：工具反馈信号只在覆盖的族类内起效（[1] New-type-A 仅维持不创造），能力边界随交互链长收缩（[3]），且外化载体同时是系统性风险放大器（[6] 工具注入劫持工作流、[5] 平均 ASR 47.1% 且长视野升至 80%）。[8] 的图重写框架提示工具契约漂移会级联影响上层技能与工作流，但目前缺级联实证。总体而言，工具与工作流是一种强大但需外部判定器/稳定检索基线兜底、并伴随安全外部性的外化进化范式；其跨层统一的形式化收敛保证与非仿真环境下的安全鲁棒性，是当前文献的明确缺口（answer_completeness: partial）。
