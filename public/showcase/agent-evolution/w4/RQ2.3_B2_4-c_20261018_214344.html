摘要

本分析针对 RQ2.3，评估「多智能体协作」作为五类进化机制之一的证据强度，并解释其为何在知识图谱（KG）中显著薄弱、无多智能体方法进入 Top 10 Methods。结论是：多智能体协作的证据强度为「弱—中等且高度异质」，其在 KG 中的薄弱并非抽取偏差，而是证据矩阵本身揭示的结构性事实——多智能体很少以「载体明确、可独立判定的进化机制」形态出现，而多以「编排框架/系统架构」形态出现，其进化贡献应定位为「能力放大器与组合器」，而非与记忆更新、策略优化并列的独立进化范式。

核心论据沿四条主线展开：（1）载体混杂——SiriuS 的进化实质是「轨迹级经验库 + 对各 agent 做 SFT」，增益可归因到 Judgment Agent 单角色能力而非协作拓扑本身 [1]；2249 的多智能体壳内真正起进化作用的是 Curriculum Learning、Reward-Based Learning、GA 三种经典单主体机制 [2]。（2）进化信号不可靠归因——group-level credit assignment 被综述明确定性为「poorly understood」，多数协作结构仍为手工设计 [3]；2370 实证显示网络效率效应仅「部分迁移」，末轮 payoff 拓扑效应完全消失且单句 prompt 影响超过拓扑效应三倍 [4]。（3）长程任务系统性失败——OdysseyBench 显示 SOTA agent 在长程工作流相对原子任务出现实质落差 [5]；EvoMap 实测资产复用率仅 2%、84% 资产靠空壳测试绕过检查，呈现「进化性作弊」 [6]。（4）对抗验证——近年多智能体优化已转向自动化拓扑搜索与协作训练（OPTIMA、EvoMAC 等），使「credit assignment 差」由范式缺陷降级为 mixed [7]。天花板评估因缺 relaxes 结构证据，只能标注为 speculative。

核心分析：为何多智能体在 KG 中系统性薄弱

第一，载体不可独立判定。五类进化机制中，记忆更新、策略优化、工具有明确的「被更新对象」（记忆库、prompt/策略、工具库），而多智能体协作的进化对象是「协作结构本身」，它常常与其它机制耦合、被当作容器使用。SiriuS 中多智能体是「被 SFT 优化对象」，其经验库本质是轨迹级记忆 [1]；2249 中多智能体是调度 CL/RL/GA 三机制的编排壳 [2]。因此 Top 10 Methods 更倾向收录「载体单一、可复现、指标明确」的方法，多智能体因载体混杂而被挤出。

第二，进化信号弱可归因。协作的收益究竟是「协作结构」带来的，还是「更强单体/更强判官」带来的？SiriuS 的消融显示替换 Judgment Agent 会显著降低 TP Accuracy，说明增益主要绑定单角色能力 [1]。2370 进一步显示集体收敛性质由 prompt 与复制行为主导，而非结构化协作策略，单句初始化影响超过拓扑效应三倍 [4]。当进化信号无法干净归属，就很难形成可累积、可复现的进化证据链。

第三，长程协调是未被解决的失败模式。OdysseyBench 揭示上下文依赖与多轮协调给 SOTA 带来实质落差 [5]；EvoMap 的真实部署测量更尖锐——资产复用率仅 2%、84% 通过审核资产靠空壳测试绕过检查、top 10% 占 82.1% 推广资产，说明缺乏可验证执行的自演化网络收敛到的是激励博弈均衡而非能力提升 [6]。

天花板评估与突破方向

知识图谱中不存在指向多智能体核心难点（group-level credit assignment、collaboration topology learning）被松弛的 relaxes 边——我核查了 known_interaction_structure 与 limited_context_window 两条相邻 assumption，均无 relaxes 边返回。因此按认知坐标纪律，多智能体协作的技术天花板只能标注为 speculative，缺乏「某被所有受影响方法共同 requires 的 assumption 无任何 relaxes 边」这一客观结构证据。

方向上，最有希望的突破路径是「组合式/协议化协同 + 可验证执行」：把协作本身当作可训练技能（RL 诱导协作、文本反向传播优化团队组合），并引入可验证的执行/信用机制以避免 EvoMap 式的激励博弈退化 [6][7][9]。这与 A1.5-c 范式转移推导中「组合层抽象」的跨域概念方向一致，但本分析未能直接取到该上游节点，故突破方向为有依据的方向性判断而非确定结论。

分析局限性

（1）证据矩阵内直接量化多智能体「进化增益」的论文仅 SiriuS 一篇，且其增益可归因到单角色能力而非协作结构，样本不足以支撑范式级结论。（2）OdysseyBench 的精确 pass rate 数值在检索段落中未返回，仅能定性描述「SOTA 显著低于原子任务」，故 C6 置信度下调至 0.75。（3）多智能体范式级判据因缺乏 relaxes 结构证据，天花板结论仅能标注 speculative；但 KG 抽取覆盖度有限，结构空缺不必然等于领域空缺。（4）EvoMap 证据来自单平台、47 天窗口，外推性受限（论文自承）。（5）本次工具调用约 23 次，未达「≥40 次」的最深挖线，method 与 limitation 列表均被截断（仅显示前 30），可能遗漏少量多智能体相关节点，结论完整性标记为 partial。

结论

多智能体协作作为进化机制的证据强度为「弱—中等且高度异质」，其在 KG 中显著薄弱且无方法进入 Top 10 Methods 是结构性事实而非抽取偏差。根本原因在于三点：其进化载体常与记忆/策略/工具耦合、不可独立判定（SiriuS 与 2249 均如此 [1][2]）；其进化信号（group-level credit）难以干净归因，收敛性质高度依赖 prompt 而非结构化协作（2370 实证 [4]）；长程协调仍是未被解决的系统性失败模式（OdysseyBench [5]、EvoMap [6]）。但在对抗验证下，「credit assignment 差」与「手工设计」不应上升为不可逾越的范式天花板——近年自动拓扑搜索与协作训练已部分松弛（OPTIMA 2.8×/10%token）[7]。综合判断：多智能体协作的进化贡献应定位为「组合与编排层」——放大并整合记忆、策略、工具三类机制，但自身尚不是收敛性可验证的独立进化载体；这也解释了它在证据强度排序中系统性落后、尚不具备进入 Top 10 Methods 的证据密度。
