摘要

本报告针对子问题 RQ4.2「联邦学习相关约束（如 bounded gradients、client-aided model、delay-free communication）如何映射到多智能体协作的隐私与去中心化训练场景」进行了系统的能力-风险因果链分析。核心结论是：这三条 FL 约束在多智能体场景中并非中立的技术细节，而是同时承担「使能」与「引入攻击面」双重角色——它们既是被设计用来降低通信/计算开销或保障隐私的机制，又各自对应一条难以通过纯工程补丁消除的内生风险链。

第一条链（bounded gradients → 梯度泄露）：FL 默认「只共享梯度不共享数据即安全」，但 iDLG 通过交叉熵损失梯度符号分析证明共享梯度「确定性地」泄露 ground-truth 标签，可 100% 精度提取真实标签并在 MNIST/CIFAR-100/LFW 上实现高保真数据重建 [1]。第二条链（client-aided model → 合谋假设风险）：client-aided 2PC 模型的安全性唯一依赖「计算方不得与分发 Beaver triples 的客户端合谋」这一强假设，一旦被打破则隐私保证整体崩塌 [2]；在 MAS 中它映射为对聚合节点的 semi-honest 信任假设 [3]。第三条链（delay-free communication → 协作语义崩塌）：跨决策区间的信道延迟导致异步消息、认知偏差甚至协作崩溃，性能可劣于完全不通信 [4]；在联邦去中心化训练语境中对应同步聚合前提，而统计异构会使 FedAvg 发散 [5]。

核心分析一：bounded gradients 与梯度泄露链

FL 的 bounded gradients 约束建立在「梯度交换不泄露数据」的隐含信念之上。iDLG 直接证伪了该信念：通过推导分类交叉熵损失对正确标签激活的梯度落在 (−1,0) 区间、对错误标签落在 (0,1) 区间，二者符号相反，攻击者可据此「确定性地」识别 ground-truth 标签并以 100% 精度提取，进而大幅简化 DLG 的优化目标、获得更高保真度的数据重建 [1]。实验覆盖 MNIST（10 类）、CIFAR-100（100 类）与 LFW（5749 类，resize 32×32）三个数据集 [1]。

该因果链对 MAS 的关键映射是：agent 间传递的编码中间特征/隐状态在可微通信协议下等价于「共享梯度」，同样面临被逆向的风险。这意味着「去中心化训练」若仍以交换可微表示为通信核心，其隐私保证是脆弱的，需要显式密码学增强（secure aggregation / DP / SMPC）。梯度有界本身即是攻击可行性的前提——梯度越受约束、搜索空间越小，匹配越容易。

核心分析二：client-aided model 的合谋信任风险

client-aided（server-aided）2PC 模型为规避同态加密与不经意传输的重开销，让一个「非计算方」客户端生成并分发秘密份额与 Beaver triples，从而显著提升离线计算效率 [2]。但其安全性唯一依赖一条强假设：任何计算方都不得与生成 BTs 的客户端合谋 [2]。这是一条「单点信任」约束，一旦合谋假设被打破，隐私保证整体崩塌。

在 MAS/去中心化训练中，这映射为「协调者/聚合服务器 semi-honest 假设」。LAFA 的威胁模型明确假定：clients 为 honest-but-curious、server 为 semi-honest 且只看到加密或加噪聚合、最终结果受 DP 保护 [3]。LAFA 坦承其隐私与安全保证「继承自底层 FA 后端」而非编排层本身——其贡献仅在编排层（自然语言→FA 工作流编译与 DAG 优化）[3]。也就是说，client-aided 式隐私在多智能体编排中被重新表述为对聚合节点的信任假设，而 LLM 编排层（planner/optimizer agent）引入了假设之外的新攻击面。

核心分析三：delay-free communication 与协作崩塌

delay-free 是 MARL 通信研究的「强假设」。CoDe 明确指出真实 agent 会遭遇跨决策区间的信道延迟，即 Asynchronous Communication，导致「认知偏差与协作崩溃」，甚至性能劣于完全不通信 [4]。CoDe 定义了两种延迟设定——fixed-delay（延迟超出决策区间，消息过时但同时发出）与 time-varying-delay（延迟随时间波动，消息在不同时刻发出），并在 SMAC、GRF、Hallway 三个基准上验证其延迟鲁棒性 [4]。

在联邦去中心化训练语境中，delay-free 对应「同步聚合/无漂移」前提。FedDANE 的研究表明：统计异构（non-IID）会使 FedAvg 发散，低设备参与度与统计异构是联邦优化性能不佳的两大根因；FedDANE 即便提供收敛保证，仍因全梯度的非精确估计持续劣于 FedAvg/FedProx [5]。映射到 MAS 意味着：去中心化训练在真实网络下必然面对异步消息与策略非平稳，而隐私协议（如 SS-based MPC 需要大量通信轮次）在 WAN 高延迟下性能瓶颈突出 [2]。

核心分析四：通信行为层隐私与对抗攻击面

FL 约束迁移的一个关键盲区是「通信行为层」隐私。Whispering Agents 指出：标准 A2A 协议用强加密保护消息内容，但无法阻止强大对手监控通信行为本身——在金融、国家安全等高风险场景中，「某些 agent 正在交互」这一事实即可泄露关键战略信息 [7]。该工作形式化了首个统一的 Covert Event Channel 模型，涵盖 Storage、Timing、Behavioral 三个维度，并提出 Pi-CCAP 协议，实现在 LLM-based warden 面前不可察觉的高容量隐蔽通信 [7]。

在对抗鲁棒性方面，Tu 等人研究了多智能体通信上的对抗攻击：受损信道可被用于执行对抗攻击，且鲁棒性随良性/恶意 agent 比例升高而增加；迁移攻击更实用但需对齐中间表示分布 [9]。AiTM 攻击进一步将此扩展到 LLM-MAS：攻击者拦截并操纵 victim agent 的通信即可实现 DoS 与定向行为诱导，在 MMLU、HumanEval、MBPP 上验证 [8]。TAMAS 基准则系统化评测：含 300 个对抗攻击场景与 100 个良性场景，覆盖 5 个领域与 6 类攻击（直接/间接 prompt 注入、Impersonation、Byzantine agent、Colluding agents、Contradicting agents），实验表明多智能体框架高度易受攻击 [10]。

能力-风险因果链的不可规避性评估

依据因果强度分类标准（Strong：confidence ≥ 0.8 且 ≥2 个独立来源；Moderate：confidence ≥ 0.6 或单源明确论证），本分析对每条链执行「删除该能力是否导致系统核心功能丧失」的对抗性验证：

不可规避（inherent）风险：(1) 梯度/表示交换是去中心化可微训练的核心机制，删除则丧失联邦学习协同训练能力，故梯度泄露是内生风险 [1]；(2) 跨组织协作本质上需要隔离私有数据，AgentNet 表明去中心化架构是规避中心单点与数据孤岛的必选路径，但其 RAG 记忆池的新攻击面随之而来 [6]；(3) 通信行为本身是实现多 agent 协作的必要条件，只要 agent 交互就存在流量分析面 [7]；(4) 去中心化训练在真实网络下无法假设零延迟，异步性与非平稳性是分布式学习的内在属性 [4][5]。

可缓解（mitigable）风险：client-aided 模型的合谋假设、DP 预算分配、以及具体聚合算法（FedAvg/FedProx/FedDANE）的选择属于工程层决策，可通过算法设计与协议增强部分规避 [2][5]。Constraint Drift 亦可通过 Constraint State Governance 等机制缓解 [13]。

因果强度纪律说明：Strong 级链（iDLG 梯度泄露 0.95、Whispering Agents 通信隐私 0.95、AiTM 0.95）均有 KG 边 confidence ≥0.95 且具备跨论文或多证据支撑；Moderate 级链（client-aided 合谋 0.9、CoDe 延迟 0.9、FedDANE 异构 0.9）多为单源明确论证。Weak 级链（无直接文献支撑、仅逻辑推断）在本报告中被排除或明确标注，不应作为最终结论。bounded gradients、client-aided model、delay-free communication 三个 KG 假设节点本身无出边，其约束→风险的连接由关联论文（iDLG、client-aided 2PC、CoDe、FedDANE）间接建立，属于 Moderate 强度推断。

分析局限性

本分析存在三方面证据覆盖不足：

(1) 证据矩阵与实践脱节：本子问题冻结的六篇论文（MCCD、DesignGPT、longagent、ColaCare、MultiAgentESC、NADER）均为「应用型」多智能体协作系统，其 KG 关系主要集中在任务性能、幻觉缓解与协作框架层面，未直接讨论 FL 的 bounded gradients/client-aided/delay-free 约束的迁移问题。因此三条核心因果链需依赖证据矩阵之外的关联论文间接建立。

(2) KG 假设节点孤立：bounded_gradients、client_aided_model、delay_free_communication 三个假设节点在 KG 中无任何出边（get_relation 返回空），约束→问题节点的直接因果边缺失，本报告的映射基于同主题论文的语义关联，而非 KG 原生因果边，属 Moderate 置信度推断。

(3) 缺少端到端实证：现有证据中不存在「在真实 LLM-MAS 上执行梯度逆向攻击并量化隐私泄露」的直接实验，iDLG 的攻击在经典 ML 模型（MNIST/CIFAR/LFW）上验证 [1]，CoDe 的延迟在 MARL 基准上验证 [4]，二者的 MAS/去中心化训练迁移性尚未被联合验证。此外，AgentNet 的隐私主张更接近设计理念而非量化结论 [6]，LAFA 的隐私保证完全继承自后端 [3]，二者对编排层自身隐私风险的评测均不充分。

结论

联邦学习的三条约束向多智能体协作场景的映射揭示了一个「约束即风险」的耦合结构：bounded gradients 的可微表示交换机制是梯度逆转隐私泄露的前提；client-aided model 的高效性建立在对聚合节点的合谋信任假设之上；delay-free communication 的同步前提掩盖了异步通信与去中心化训练的非平稳性。这三条链分别对应隐私泄露、信任单点失效与协作语义崩塌三类威胁面，且均可溯源至 KG 中的假设节点与问题节点。

对防护覆盖的评估表明：现有机制（DP、secure aggregation、SMPC、HE、TEE）主要保护「消息内容」，而对「通信行为本身」（流量分析/监视）[7]、agent 间通信的中间人操纵 [8] 与多智能体对抗攻击（含 Byzantine/Colluding agents）[10] 覆盖薄弱。分歧点在于：AgentNet 等主张去中心化天然有利于隐私 [6]，LAFA 则强调隐私保证来自后端而非编排层 [3]；安全约束在 LLM-MAS 轨迹中的 constraint drift 又进一步侵蚀了静态防护的有效性 [13]。因此，将 FL 约束迁移到多智能体协作时，必须把隐私视为系统级属性，并同时覆盖内容层与行为层、并针对异步与非平稳环境重新设计鲁棒聚合协议。
