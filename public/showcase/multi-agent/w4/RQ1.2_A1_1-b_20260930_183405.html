摘要

本报告针对子问题 RQ1.2「现有工作提出哪些错误传播抑制或行为锚定机制，它们分别作用于协作流程的哪个阶段」，以 6 篇冻结证据论文（ChaosEater[1]、NADER[2]、MCCD[3]、RoCo[4]、DesignGPT[5]、ColaCare[6]）为核心，并补充知识图谱中同语料的高相关论文（0203[7]、0206[8]、0176[9]、0210[10]、3835[11]、3836[12]、3839[13]）作为证据。

分析首先从文献中归纳出六阶段协作流程模型（S1 规划分解 → S2 知识检索/接地 → S3 生成/执行 → S4 验证/校验 → S5 协调/辩论 → S6 事后整合/部署），进而将抑制机制归纳为五大类：结构化验证/形式化校验、结构化交接与问责、对抗性辩论与共识、元认知反思/经验库、行为锚定与漂移治理。结论显示：抑制机制高度集中在「验证/校验」与「协调/辩论」阶段，而「规划分解」与「长时部署」阶段被系统性低估；最强的量化有效性证据来自验证类机制（如 CHASE 召回 0.984、假阳率 0.08%[9]；NADER 成功率 0.62→0.88[2]），但各类机制缺乏统一的「错误抑制率」评测口径。

本次分析覆盖知识图谱七类节点：Problem（问题）454 个、Method（方法）380 个、Paper（论文）186 篇、Dataset/benchmark 243 个、Metric（指标）278 个、Limitation（局限）170 个、Assumption（假设）119 个。

跨阶段错误传播链

文献提供了错误跨阶段级联的具体证据：RoCo 观察到「一个 agent 出错会使后续对话建立在错误推理上」——某 agent 误判任务完成后，其他 agent 附和并等待，导致任务实际未完成[4]；GUARDIAN 形式化了幻觉放大与错误注入的传播不等式（∑h_t,i ≥ ∑h_{t-1,i}）[13]；0203 的失败分类显示规划阶段错误（不当分解、失败自细化、不现实规划）会级联至执行与响应生成阶段[7]。这表明仅在验证阶段设置拦截点，不足以阻断源头规划错误向生成、协调阶段的级联。

被低估的阶段：S1 规划与 S6 长时部署

证据一致指向两个被低估的抑制点。第一，规划阶段：问责管线研究明确指出「Planner 的杠杆最大，其错误率是管线失败的最强预测因子」[10]，0203 亦将规划错误列为三大失败类之首[7]；然而冻结的 6 篇论文中，仅 ReDeFo 的 Analyst 在需求阶段通过细化与形式化来消歧[8]、DesignGPT 通过 SOP 前置约束角色行为[5]触及规划前置抑制。第二，长时部署阶段：Agent Drift 报告 agent 漂移「几乎影响半数长时 agent，导致任务成功率下降 42%、人工干预需求增加 3.2×、inter-agent 冲突增加 487.5%」[11]，但该类机制目前以仿真外推为主，几乎没有真实部署验证，且冻结证据集中无一篇设置专门的部署后监控机制。

机制有效性的分歧点与不确定性

分析揭示三处主要分歧与不确定性。第一，评测口径不一致：验证类机制给出错误检出率/假阳率（如 CHASE 召回 0.984[9]、GUARDIAN 检测率>80%[13]），而设计类与临床类机制给出的是任务结果提升（DesignGPT 完整性 +24.26%[5]、ColaCare AUROC[6]），二者无法直接比较。第二，有效性来源的可信度差异：行为锚定/漂移治理的效果（67–81% 错误削减）来自模拟框架的投影而非真实部署[11]，其外推效度存疑。第三，机制成本与前提条件：问责管线以成本 2–3×、延迟 8–10×（约 20–25s）为代价[10]，且归因假设可获取 ground-truth 标签；约束状态治理亦假设完整审计记录可重建[12]，在开放部署中均难以满足。

本报告所有结论均标注证据来源。标为「仿真外推」的结论（Agent Drift 的 67–81% 错误削减）来自模拟框架，非真实系统验证；标为「机制」的条目为定性描述，其量化有效性未被原始论文直接给出。

分析局限性

1）数据覆盖：冻结的 6 篇证据论文中，仅 NADER[2]、ChaosEater[1]、RoCo[4] 提供了较清晰的抑制机制与量化效果，其余（MCCD[3]、DesignGPT[5]、ColaCare[6]）以任务结果指标为主，缺少错误抑制率的直接测量。

2）证据外推：行为锚定、漂移治理、约束保持类机制主要来自同语料扩展论文（Agent Drift[11]、约束漂移[12]），且多为仿真或可重放反事实验证，真实部署有效性待验证。

3）阶段归类的主观性：阶段归属主要依据 description 字段与原文语义判断，部分节点（如「非平稳性 moving-target problem」）超出六阶段模型，归类失败率约 1/20，提示模型可能存在微小覆盖漏洞。

4）传播链证据不完整：跨阶段传播链有定性证据（RoCo[4]、GUARDIAN[13]），但缺乏定量传播率，无法量化各阶段的「传播能力」与「被污染程度」。

5）评测标准缺失：不同论文的错误抑制定义与评测口径割裂，尚无统一的错误传播抑制率基准。

结论

针对 RQ1.2，本研究得出三点结论：其一，现有错误传播抑制/行为锚定机制可归纳为五大类（结构化验证/形式化校验、结构化交接与问责、对抗性辩论与共识、元认知反思/经验库、行为锚定与漂移治理），其中前三类集中在验证/校验与协调/辩论阶段[1][2][4][6][9][10]。其二，机制有效性证据高度集中于验证类：NADER 成功率 0.62→0.88[2]、CHASE 召回 0.984 且假阳率 0.08%[9]、GUARDIAN 检测率>80%[13] 是当前最强的量化证据；而设计/临床类机制多报告任务结果提升而非错误抑制率。其三，阶段覆盖严重不均——S4 验证与 S5 协调已研究饱和，而 S1 规划（Planner 错误率是失败最强预测因子[10]）与 S6 长时部署（agent 漂移导致成功率下降 42%[11]）是被低估的抑制点，且错误跨阶段级联证据[4][13]表明仅在验证阶段拦截不足以阻断源头错误的传播。未来研究需建立统一的错误传播抑制评测基准，并向规划源头抑制与部署后漂移治理两端延伸。
