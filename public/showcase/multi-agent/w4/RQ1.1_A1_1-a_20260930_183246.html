摘要

本报告针对子问题 RQ1.1（协作过程中被明确命名的失效模式及其触发条件与表现形式），对知识图谱进行系统性挖掘，共识别出 12 类在文献中被明确命名的多智能体协作失效模式。其中三类构成错误传播与行为退化的主干：agent drift（智能体漂移，含 semantic/coordination/behavioral 三子类）[1]、constraint drift（约束漂移，含 memory/authority/information-flow/accountability/utility-induced 五诊断模式）[2]，以及 error cascade 与 cascading hallucination（错误级联与级联幻觉）[3][4][5]。

分析发现，这些失效模式共享一个结构性根源：在多智能体轨迹中，信息、意图与约束在委托、通信、记忆与优化的接口处被反复传递时发生衰减或扭曲。触发条件可归纳为四类：长交互序列与任务模糊性（drift 家族）、多步委托与工具调用（constraint drift）、串行管线中缺乏结构化交接（error cascade）、以及缺乏组织结构的自发协作（无效通信）。表现形式均已获得不同程度的量化证据，最强的一条是漂移导致任务成功率下降 42%、智能体间冲突增加 487.5%。

失效模式归类与横向比较

从触发机制角度，12 类失效模式可组织为五大家族：

（1）渐进式行为退化类（Drift Family）：以 agent drift 为代表 [1]，触发于长交互序列与任务模糊性，表现为行为、决策质量与智能体间一致性的渐进退化。其证据主要来自模拟（847 个模拟工作流），属投影值而非生产实测。

（2）约束保持失败类（Constraint Drift Family）：以 constraint drift 为代表 [2]，触发于多步委托、上下文总结与工具调用，表现为安全关键约束丧失操作效力。该论文目前属 position paper，五模式为诊断性而非互斥。

（3）级联传播类（Cascade Family）：包括 error cascade [3]、cascading hallucination [4] 与 hallucination amplification [5]，触发于串行管线缺乏结构化交接或智能体间网络化交互。这类模式的证据最硬——[3] 基于真实 benchmark 实证给出可量化归因方法，[5] 报告各数据集幻觉放大检测率在 66.9%–94.7% 之间。

（4）协调与通信失效类：包括六种无效通信行为 [7]、agent behavioral conflicts 与 memory inconsistency [6]、asynchronous communication breakdown [8]。其共同触发条件是团队缺乏组织结构或时序约束缺失。[7] 的实证显示，指派领导者后团队完成时间显著缩短。

（5）规划与终止异常类：以 improper task planning / failed self-refinement（无限循环）为代表 [9]，基于 34 个任务、204 次运行的实证，构建了 task planning / task execution / response generation 三层分类法，当前框架仅约 50% 成功率。

此外，[10] 从系统治理层面命名了三类根因性失效（不透明协作、缺失激励、可扩展性受限），为上述技术性失效提供了「为何发生」的制度解释。

核心结论

第一，RQ1.1 所问的「被明确命名的失效模式」在文献中至少存在 12 类，且已有明确的问题节点定义（canonical_name 与 description 字段），证明该领域已具备初步的失效模式分类学。

第二，三类主干失效模式——agent drift [1]、constraint drift [2]、error cascade [3]——分别对应「渐变式退化」「系统级约束失效」「突变式错误传播」三种不同的错误传播机制，而非同一现象的重复表述。它们共同揭示：多智能体协作中的错误并非均匀传播，而是在委托、通信、记忆与优化的接口处被放大或扭曲。

第三，各失效模式的证据强度不均。级联传播类与规划异常类基于真实 benchmark 实证，证据最硬 [3][9]；行为退化类主要基于模拟，是投影而非实测 [1]；约束漂移类尚属 position paper [2]。这构成本子问题的首要证据缺口。

分析局限性

第一，证据类型偏差。drift 家族 [1] 与制度性根因 [10] 的量化结论均来自模拟或受控实验，未经真实生产系统验证；ASI（Agent Stability Index）等度量缺乏独立复现。

第二，基准不可比。各失效模式的量化数字（如 [1] 的 42% 成功率下降、[9] 的约 50% 完成率）来自不同的任务集、模型与实验设置，方向一致但不可直接叠加或横向比较。

第三，单一来源风险。agent behavioral conflicts 与 memory inconsistency [6] 来自单一框架论文的问题陈述，constraint drift [2] 来自单篇 position paper，均未见跨系统验证。

第四，维度遗漏。真实高维失效空间至少还存在一个第三维度——失效是「内生自发」还是「对手/恶意诱发」（如 error injection 属对抗诱发 [5]，drift 属内生自发 [1]），该维度影响约 15%–20% 的问题节点，本报告的二维归类未能完全覆盖，建议后续用分层堆栈方法补充。

第五，数值不确定性。部分百分比（如幻觉放大检测率 66.9%–94.7% [5]）随数据集与任务类型波动较大，单一数值不具跨场景代表性。

结论

针对 RQ1.1，本分析基于知识图谱 454 个 Problem 节点及 10 篇关键论文的原文精读，识别并命名了 12 类多智能体协作失效模式，其中 agent drift（三子类）[1]、constraint drift（五模式）[2] 与 error cascade / cascading hallucination [3][4][5] 为三大主干。这些失效模式的触发条件可归纳为长交互序列、多步委托、串行管线缺乏结构化交接与团队缺乏组织结构四类；表现形式均已获得不同程度的量化支撑。分析同时揭示了证据强度不均、基准不可比、维度遗漏三大局限，为后续子问题（抑制机制分类与有效性评估，即 RQ1.2）提供了结构化的现象清单与冷区定位。
