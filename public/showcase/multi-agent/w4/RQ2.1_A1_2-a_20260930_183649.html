摘要

本报告针对子问题 RQ2.1「现有协作架构可沿哪些设计维度分类（如编排拓扑、角色分配方式、SOP 结构化程度）」，基于知识图谱中论文、方法、问题、局限、假设、指标六类节点的结构化数据与 14 篇关键论文的原文段落证据，进行正交解耦分类学分析。

核心结论：证据矩阵中的文献并不提供统一分类，而是并行提出了至少五套互不兼容的方案——[1] 的协调形式三分与星/环/图/总线四模式、[2] 的等层/层级/嵌套/动态四结构、[3] 的 9 维度、[4] 的五种工作流模式、[5] 的链/树/图三拓扑。这些方案对同一事物使用不同名称，存在严重类别重叠。经正交化重构，可将被讨论的全部协作架构归入两个本质维度构成的 2×2 矩阵：维度 A「编排拓扑」（集中式 / 去中心化）刻画协调决策的归属点；维度 B「角色制度」（固定式 / 演化式）刻画角色与分工是否随任务变动。该二维空间的不同格子经实验证实在任务适配上各有边界，构成 RQ2 所问「适用边界与权衡」的分类学基础。

一、现有分类方案盘点：五套并行且互不兼容的体系

从论文节点 description 与原文段落中，共提取出五套被文献实际采用的分类方案。按被引用/自述的显式程度排序，它们均属「主流分类」而非边缘分类，因为每套都由至少一篇高被引或顶会论文系统提出。

这些方案的共同特征是：各自使用独立的术语体系，且从未互相引用对方的分类标准，导致同一架构实体在不同方案中拥有不同标签。[1] 明确按协调形式给出「完全集中式 / 带全局信用分配的去中心化 / 完全去中心化」三分，同文又按实现形态给出 Star / Ring / Graph / Bus 四类架构模式；[2] 按结构给出 Equi-level / Hierarchical / Nested / Dynamic 四类；[3] 提出覆盖通信策略、通信对象、约束、消息内容等的 9 个维度；[4] 归纳出 Chain / Parallelization / Routing / Orchestrator-Workers / Evaluator-Optimizer 五种工作流模式，并区分静态与动态执行；[5] 按拓扑给出 chain / tree / graph 三类，并提炼 density / shape / direction 三个分析视角。

二、现有分类的缺陷诊断

对上述五套方案进行 MECE（互斥且穷尽）检验，发现三类缺陷：

（1）类别重叠（Overlap）。多套方案存在命名层面的重复：「Star 架构」[1] ≈「Hierarchical 结构」[2] ≈「Orchestrator-Workers」[4]；Bus [1]、Ring [1]、Chain [4][5] 三者均落在「顺序/流水线」语义上，构成典型类别重叠。

（2）维度混用（Ambiguity）。[2] 将「动态结构」（角色、关系、智能体数量随时间变化）与「Equi-level / Hierarchical」并列，但二者在分类标准上正交——前者描述时间演化性，后者描述层级拓扑，属维度混用缺陷。[3] 作者本人承认其 9 个维度「不天然相互依赖……但具体实现会产生依赖」，例如有限带宽约束会使 full communication 类别不可行，为「现有分类未满足正交性」提供了文献自证。

（3）SOP 结构化程度未解耦。[1][4][11] 广泛讨论 SOP/固定工作流，但始终将其与编排拓扑混为一谈，未识别其为独立的角色制度维度。

诊断依据：重叠检测通过跨文献术语比对完成（非单一论文自述，故标注 diagnosis_source: empirical_observation）；正交性缺陷由 [3] §3.10 原文自证支撑（diagnosis_source: literature_acknowledged）。

三、正交重构维度

从 Problem 节点的本质属性归纳，所有被方法针对性解决的问题都落在两条相互正交的谱上：

维度 A —— 编排拓扑（Orchestration Topology）：刻画「协调决策的归属点」。取值 {集中式, 去中心化}。证据：[6] 针对「静态组织结构 static organizational structures」采用集中式 puppeteer 编排器；[7] 针对「单团队固定决策路径」采用跨团队编排；[12] 批评集中式控制的单点故障、扩展性差、跨组织隐私壁垒；[9] 针对集中式 LLM 分析的隐私风险采用去中心化联邦数据；[10] 从奖励分配角度证明去中心化执行的可行性。

维度 B —— 角色制度（Role Regime）：刻画「角色与分工是否随任务变动」。取值 {固定式, 演化式}。证据：[8] 针对「冗余的智能体角色与信息交换」，明确批评固定角色在多轮讨论中的低效；[2] 把「动态结构」单列；[11] MetaGPT 以 SOP 固化五大固定角色；[12] 通过 RAG 记忆实现角色动态专精。

正交性依据：[3] 对 communication policy 按「预定义 vs 可学习」与「个体控制 vs 全局控制」的交叉分类，说明编排归属与角色制度在分类标准上互不依赖。

四、任务适配边界：分类空间各格子的实验证据

[5] 在六个代表拓扑上的实验直接证实该二维空间存在任务适配边界：没有单一拓扑在所有任务上占优——链式拓扑利于软件开发（线性流程：分析、编码、评审、测试），树式拓扑利于创意写作（需发散结构）；且交互密度越高平均表现越好，mesh > tree > chain。这为「不同格子各有权衡」提供了量化依据。

在角色演化轴上，[8] AgentDropout 的动态角色消除在 Llama3 上较 SOTA AgentPrune 提升 2.19 个准确率点（LLM 提升 0.77、LLM 提升 0.47），并显著降低 token 消耗；[7] Croto 消融显示去除层级分区使 4/8 团队解质量从 0.789/0.775 降至 0.756/0.773，去除聚合智能体角色分配进一步降至 0.735/0.744。

在编排拓扑轴上，[6] 明确 advocate 集中式编排并「contradicts」去中心化的 [12]；而 [12] 反过来批评集中式的单点故障与隐私壁垒；[1] 则提出「带全局信用分配的去中心化」折中态，并以其集中式星架构案例中所有数据须流经 Orchestrator 带来的隐私风险 vs 去中心化星架构让专用智能体独立处理敏感数据的对比，说明维度 A 实为连续谱而非二分。

五、新旧分类对比：缺陷解决情况

新体系通过将五套混乱方案收敛为两个正交维度，实质性地解决了三类旧缺陷：

对于类别重叠：原来的「Star / Hierarchical / Orchestrator-Workers」三名一事，在新体系中统一归为「集中式」取值；「Bus / Ring / Chain」三名一事统一归为「顺序流水线」在维度 B 固定式一端下的具体实现。

对于维度混用：[2] 中「Dynamic」这一与层级标准正交的类别，在新体系中回归为维度 B 的「演化式」取值，与拓扑维度彻底解耦。

对于 SOP 未解耦：SOP 结构化程度被明确归入维度 B 的「固定式」一端，与编排拓扑分离。

分析局限性

本分析存在三方面局限：

（1）重构推断性。两维度（编排拓扑、角色制度）的命名与正交性、以及 SOP 结构化程度归入维度 B，均为跨文献重构推断，缺乏单一论文的直接命名与消融验证。原文献从未显式提出这两个维度的术语，故置信度标为 0.70-0.75。

（2）量化证据缺口。多数分类论文（[1][2][3][4]）为综述/立场性工作，未在统一基准上量化比较各格子；「角色演化」主要由 [8][12] 以效果性指标（准确率、token）间接论证，缺少对维度 B 的直接消融实验。

（3）覆盖范围。证据矩阵仅 6 篇冻结论文，多数架构实例需借助冻结集合外的相邻论文（[5][11][12][14]）补充。分类普适性受限于证据集合的领域分布（软件工程、推理、联邦分析为主），对机器人、具身等领域的迁移性未验证。

证据一致性与分歧：[6] 与 [12] 在集中式/去中心化优劣上明确对立（KG 中以 contradicts 边记录），提示维度 A 在文献中存在真实学术分歧，而非单纯分类学分歧。

结论

RQ2.1 的答案是：现有协作架构的分类不应沿用文献中五套并行且互不兼容的方案，而应收敛为两个正交维度的 2×2 矩阵——维度 A「编排拓扑」（集中式 / 去中心化）与维度 B「角色制度」（固定式 / 演化式）。该二维空间可将证据集合中全部被讨论的架构无歧义地归类，并消除旧分类的命名重叠、维度混用与 SOP 未解耦三类缺陷。实验证据表明，各格子在任务适配上各有边界（链式利软件工程、树式利创意写作 [5]），且维度 A 实为连续谱（[1] 的折中态），维度 B 的演化式在准确率与 token 效率上均占优（[8] 提升 2.19 点）。这一分类学基础直接回应了父问题 RQ2 关于「集中式/去中心化、固定/演化角色在任务编排层面适用边界与权衡」的追问：适用边界由任务结构（线性 vs 发散）与约束（隐私、扩展性、成本）决定，权衡则体现在解质量、token 成本、容错性与隐私之间的取舍。后续研究需在统一基准上量化比较各格子，并对角色演化维度开展直接消融以验证本重构体系。
