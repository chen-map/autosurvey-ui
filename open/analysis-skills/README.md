# 分析工作流库（37 个策略）

这是一组面向文献综述的分析策略规范，用 Markdown 声明式描述“什么问题、用什么分析动作、需要哪些输入、输出什么”。它们不是某个模型的专属提示词，而是可被任意 Agent / 流水线读取的任务规范。

## 结构

- `problem_space/`：18 个策略，回答“问题是什么、从哪来、缺什么、往哪走”。
- `solution_space/`：19 个策略，回答“方案怎么分类、怎么比、评估是否可比、离落地多远”。
- `INDEX.json`：全部策略的编号、标题、RQ 类型、简介与路径。

每个策略文件包含：

- 名称与一句话描述（frontmatter）
- 适用层级与 RQ 类型
- 分析逻辑与认知基准
- 输入（知识图谱节点/边、论文卡片、RQ）
- 执行步骤与可用工具
- 输出结构（表格/清单/谱系/矩阵）

## 使用方式

1. 读取 `INDEX.json`，按 RQ 类型筛选候选策略。
2. 让 Agent 读取候选策略的 Markdown，选择最匹配的一个。
3. 按策略的输入要求，从自己的语料/图谱中取数。
4. 按输出结构生成报告；无法取到的字段留空并标注，不要编造。

示例：

```text
RQ：不同任务目标对应什么技术架构？
候选：B2.1-b 任务-机制正交矩阵
输入：methods（含 task_type / architecture_type）
输出：任务×架构密度矩阵 + 空白象限说明
```

## 设计原则

- **证据约束**：每个判断应能回到论文或图谱节点；取不到证据时明确标注缺口。
- **可比较**：优先输出矩阵、谱系、覆盖率等可对照结构，而不是散点式描述。
- **不替代判断**：策略给出分析路径，结论由使用者复核。
