# Skill: A1.5-a 盲区/留白外推

**层级**：P1.5 认知空白层 · Gaps & Unknowns  
**RQ类型**：还缺什么？（覆盖缺口）  
**元认知逻辑**：扫描 Problem Space 分类矩阵（由 A1.1/A1.2 产出），定位文献密度极低的「空白单元格」，深入分析这些空白是「技术难度高导致的研究空白」还是「认知盲区」，为未来研究方向提供精准定位。  
**认知基准面**：以「结构化盲区外推」为透镜——研究矩阵中的空白单元格本身就是研究机会的信号，但必须先区分「真空白」（该类型问题现实存在但无研究）和「假空白」（逻辑上不可能的问题组合），再按「危害×可行性」乘积排序，而非直觉排序。

---

## Goal

基于上游矩阵分析结果，系统性地扫描所有文献密度极低（≤1篇）的分类单元格，对每个盲区进行深度溯因分析，区分不同类型的盲区成因，输出有优先级排序的「研究盲区清单」。

---

## Inputs

- `working_memory/rq_{id}/A1.1-a_matrix_report.json` — 上游正交矩阵映射结果（**必须**，若缺失则中止执行）
- `working_memory/rq_{id}/A1.2-a_taxonomy_report.json`（可选）— 上游分类重构结果
- `working_memory/rq_{id}/A1.4-c_coverage_gap_report.json`（可选）— 上游覆盖率缺口分析
- `knowledge_graph/nodes/problems.json` — KG Problem 节点
- `paper_cards/parsed/` — Paper Cards，提取 Future Work / Limitation 章节

## Execution Steps

### Step 0: 强制前置检查

**认知目标**：A1.5-a 的全部分析建立在 A1.1-a 矩阵的结构之上——没有上游矩阵，就没有可扫描的「空白单元格」，后续所有步骤都无法执行。这不是软性依赖，是硬性前提。

```python
import os
matrix_report_path = f"working_memory/rq_{rq_id}/A1.1-a_matrix_report.json"
if not os.path.exists(matrix_report_path):
    # 强制中止，返回错误
    return {
        "error": "PREREQUISITE_MISSING",
        "message": "A1.1-a_matrix_report.json not found. A1.5-a cannot run without upstream matrix analysis.",
        "required_skill": "A1.1-a",
        "action": "Execute A1.1-a first, then re-run A1.5-a."
    }

# 加载矩阵报告
matrix_report = load_json(matrix_report_path)
```

若文件存在但为空或格式异常，同样中止并返回错误，不得尝试基于 KG 独立重建矩阵。

### Step 1: 扫描低密度单元格

**认知目标**：低密度单元格的扫描必须严格遵循 A1.1-a 的分类结果——如果此处重新分类，就破坏了跨 skill 的一致性，分析结论将无法互相引用。

从矩阵报告中筛选所有密度 = 0 或 = 1 的象限/单元格，标记为「盲区候选」：

```python
blind_spot_candidates = []
for cell in matrix_report["matrix_cells"]:
    if cell["paper_count"] <= 1:
        blind_spot_candidates.append({
            "dimension_A": cell["dimension_A"],
            "dimension_B": cell["dimension_B"],
            "paper_count": cell["paper_count"],
            "cell_id": cell["cell_id"]
        })
```

**密度统计必须严格遵循上游文献分类结果，不得重新分类。**

### Step 2: 验证盲区的现实存在性（真空白 vs 假空白）

**认知目标**：区分「真空白」和「假空白」是防止将不可能的问题组合错误标注为研究机会的关键步骤。验证方法必须基于文献检索，不能依赖 AI 的先验知识判断「此类问题现实中不存在」。

对每个盲区候选，在 Paper Cards 中检索该维度组合对应的问题是否在现实中存在：

```python
for candidate in blind_spot_candidates:
    dim_A_val = candidate["dimension_A"]
    dim_B_val = candidate["dimension_B"]
    
    # 检索两个维度的交叉问题是否在论文中被提及（即使没有研究它）
    existence_check = search_paper_sections(
        paper_cards_root="paper_cards/parsed",
        query=f"{dim_A_val} {dim_B_val} problem attack threat",
        topk=5
    )
    
    # 判断标准：score > 0.5 的命中意味着该类型问题在文献中被提及
    # → 真空白（问题存在但无研究）
    # score ≤ 0.5 或无命中 → 可能是假空白（逻辑上不可能的组合）
    max_score = max((s["score"] for s in existence_check), default=0.0)
    is_true_gap = max_score > 0.5
    
    candidate["is_true_gap"] = is_true_gap
    candidate["reality_verification"] = existence_check[0] if existence_check else None
    candidate["verification_max_score"] = max_score
```

- **假空白**（max_score ≤ 0.5 且无文献提及）：排除，不作为研究机会
- **真空白**（max_score > 0.5 或有文献提及但无研究）：保留为真盲区

### Step 3: 分析盲区成因

**认知目标**：成因分类不能仅凭「此处为空」就断言研究机会——必须通过文献检索找到「为什么研究社区没有填补这个空白」的证据。「认知盲区」的证据是近期无相关讨论，「技术难度高」的证据是文献中有明确的挑战描述。

对每个真盲区，搜索成因证据：

```python
for gap in true_gaps:
    # 搜索技术挑战证据（Future Work / Limitation 章节）
    challenge_evidence = search_paper_sections(
        paper_cards_root="paper_cards/parsed",
        query=f"{gap['dimension_A']} {gap['dimension_B']} challenge open problem",
        topk=5
    )
    # 搜索认知盲区证据（该方向几乎无讨论）
    awareness_check = search_paper_sections(
        paper_cards_root="paper_cards/parsed",
        query=f"{gap['dimension_A']} {gap['dimension_B']} unexplored understudied",
        topk=3
    )
```

成因分类标准（必须有文献支撑）：
- **技术难度高**（`technical_difficulty`）：文献中有明确提到该方向的数据不可得、攻击复现困难或评估指标缺失
- **认知盲区**（`awareness_gap`）：近 2 年内（`created_at >= current_year - 2`）无相关论文，且无文献讨论该方向
- **资源壁垒**（`resource_barrier`）：文献中提到该方向需要大量计算/数据资源
- **跨学科壁垒**（`interdisciplinary_barrier`）：文献中提到需要跨越多个学科领域

**空白单元格的外推需附带逻辑推理过程，不得仅凭「此处为空」就断言是研究机会。**

### Step 4: 评估盲区价值与优先级

**认知目标**：「高价值盲区」的定义是「高危害 × 高可行性」的乘积最大化——这两个维度缺一不可。单纯高危但技术上完全不可行的方向，短期内无研究价值；单纯可行但危害有限的方向，投入产出比低。

对每个真盲区，综合评估：

```python
for gap in true_gaps:
    # 危害潜力：优先引用 A1.4-c 的风险评级
    if a1_4c_report_exists:
        risk_level = a1_4c_report.get_risk_for_scenario(
            gap["dimension_A"], gap["dimension_B"]
        )
    else:
        # 独立评估，标注不确定性
        risk_level = "requires_manual_assessment"
    
    # 技术可行性：现有技术能否开展研究
    # 判断依据：Step 3 的技术挑战证据密度
    feasibility = "High" if not challenge_evidence else (
        "Medium" if len(challenge_evidence) <= 2 else "Low"
    )
    
    # 优先级 = 危害 × 可行性乘积
    priority_score = risk_to_score(risk_level) * feasibility_to_score(feasibility)
    gap["priority"] = "high_value" if priority_score >= 6 else (
        "medium_value" if priority_score >= 3 else "low_value"
    )
```

社区关注度：检索近 2 年内对该方向的呼吁（Future Work 提及频率）。

输出「高价值盲区」（高危害 + 高可行性）列表，按优先级排序，Top 3 附详细分析。

### Step 4a: 对抗性验证高价值盲区列表

**认知目标**：在输出最终列表之前，验证高价值盲区是否真的「无研究」——KG 矩阵的空白可能源于 KG 收录不完整，而非该方向真的无研究。

```python
for high_value_gap in high_value_blind_spots:
    # 直接全文检索，绕过 KG 覆盖局限
    direct_paper_search = search_paper_sections(
        paper_cards_root="paper_cards/parsed",
        query=f"{high_value_gap['dimension_A']} {high_value_gap['dimension_B']} method solution approach",
        topk=5
    )
    if direct_paper_search and max(s["score"] for s in direct_paper_search) > 0.65:
        # 可能存在 KG 未收录的已有研究，降级或标注
        high_value_gap["kg_incompleteness_warning"] = True
        high_value_gap["potential_existing_work"] = direct_paper_search[0]
```

### Step 5: 原文溯源验证

对所有分析结论中引用的证据，使用 `search_paper_sections` 工具在 `paper_cards/parsed/` 中精确定位原文片段：

```python
snippets = search_paper_sections(
    paper_cards_root="paper_cards/parsed",
    query="<分析结论的关键词>",
    paper_ids=[<涉及的paper_id列表>],
    topk=3
)
```

每条关键结论必须附带：
- `paper_id`：来源论文ID（对应 `knowledge_graph/nodes/papers.json` 中的记录）
- `section`：原文章节标题
- `paragraph_snippet`：原文片段（≥20字，直接引用，禁止改写）
- `score`：语义相似度分值

**无法找到原文片段支撑的结论必须标注 `evidence: unverified`，不得作为最终结论输出。**

## Key Rules

- **必须依赖上游矩阵分析结果**：若 `A1.1-a_matrix_report.json` 不存在，此 skill 必须立即中止并返回错误，不得尝试独立运行。
- 「真空白」验证必须基于 `search_paper_sections` 的实际检索结果（score > 0.5），不得由 LLM 凭先验知识判断「此类问题现实中不存在」。
- 盲区成因分析需引用文献证据：若技术难度高，需引用文献中提到该方向挑战的段落；若是认知盲区，需说明近期文献中无相关讨论。
- 优先级评估的「危害潜力」字段必须优先链接到 A1.4-c 的输出，保持跨 skill 一致性；若 A1.4-c 不可用，必须标注 `risk_level_source: independent_estimate`。
- 高价值盲区数量超过 5 个时，需按优先级排序并给出 Top 3 的详细分析。
- **认知坐标纪律**：`is_true_gap` 的判定阈值固定为 score > 0.5，不得根据分析便利性调整阈值。
