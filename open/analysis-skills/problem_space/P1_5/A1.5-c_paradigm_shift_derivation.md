# Skill: A1.5-c 范式转移推导

**层级**：P1.5 认知空白层 · Gaps & Unknowns  
**RQ类型**：还缺什么？（新兴未知）  
**元认知逻辑**：识别当前研究范式无法解释或处理的「异常现象」，引入跨域概念作为新分析框架，论证其如何开辟对「未知问题域」的探索通道，指向下一代研究范式。

---

## Goal

从 Paper Cards 的 Discussion / Future Work 章节识别当前范式的「异常现象」（无法被现有框架解释的观察），引入被文献暗示或提及的跨域概念，构建新范式雏形，为 Problem Space 的未来延伸提供理论框架。

---

## Inputs

- `working_memory/rq_{id}/A1.5-b_bottleneck_report.json` — 硬约束分析结果（强依赖）
- `working_memory/rq_{id}/A1.3-c_paradigm_shift_report.json` — 旧范式边界分析（可选）
- `paper_cards/raw/` — Paper Cards，重点提取 Discussion / Future Work / Limitation 章节
- `knowledge_graph/nodes/` — KG 全节点（用于识别跨域概念节点）
- `analyze_report/design_report.md` — RQ 定义

---

## Execution Steps

### Step 1: 识别当前范式的「异常现象」

在 Paper Cards 的 Discussion / Results 章节中，寻找以下模式：
- 「意外结果」：实验结论与理论预测相反或不一致
- 「悖论性现象」：两种有效方法在某场景下效果相互矛盾
- 「临界崩溃」：在某个参数临界点性能骤降，现有理论无法解释
- 「跨域溢出」：来自其他领域的技术意外地在此领域有效

**引入的跨域概念必须在文献集的 Future Work 或 Discussion 中有被暗示或提及，禁止 LLM 自行引入外部概念。**

### Step 2: 提取文献暗示的跨域新概念

从 Paper Cards 的 Future Work 章节，收集作者建议引入的跨领域方法/概念/框架，每个建议需记录：
- 建议引入的跨域概念名称
- 作者对其潜力的描述
- 来源 paper_id 和章节

### Step 3: 评估跨域概念的适配性

对每个候选跨域概念，评估其与当前 Problem Space 的适配性：
- 该概念是否能解释 Step 1 中的「异常现象」？
- 该概念的引入是否能开辟新的 Problem 类型？
- 该概念是否已在相邻领域被成功应用？

### Step 4: 构建新范式雏形

对最高适配度的跨域概念，构建新范式的基本要素：
- 新范式的核心假设（区别于旧范式的根本差异）
- 新范式下将产生的新 Problem 类型（推测，需标注 `speculative`）
- 新范式对现有解法的影响（部分继承 vs 全面颠覆）

### Step 5: 标注推测级别

新范式推导全程必须区分「文献有明确暗示」vs「LLM 外推」，前者可信度高，后者仅供参考。

## Key Rules

- **跨域概念必须在文献的 Future Work 或 Discussion 中有文字暗示**，纯 LLM 推断的概念必须标注 `confidence: speculative`，不得与文献支撑的概念等同呈现。
- 「异常现象」的识别必须引用具体论文的具体实验结果段落，不得泛泛描述「现有方法不够好」。
- 新范式预测的新 Problem 类型必须通过逻辑论证（why this paradigm would generate these problems），不得无根据罗列。
- 若文献集中 Future Work 章节内容极少（< 5 篇有实质性建议），必须在报告中声明「新范式推导依据不足，结论可信度低」。
- 新范式雏形中的「全面颠覆」判断需要有充分论证，不可轻易声称范式革命。
