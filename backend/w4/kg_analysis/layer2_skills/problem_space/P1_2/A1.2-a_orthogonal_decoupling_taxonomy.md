# Skill: A1.2-a 正交解耦与矩阵重构

**层级**：P1.2 认知框架层 · Conceptualization & Taxonomy  
**RQ类型**：怎么划分？（分类体系构建）  
**元认知逻辑**：识别旧分类体系的重叠/模糊痛点，提取两个更本质的正交属性，重构满足 MECE（互斥穷尽）原则的矩阵分类法。  
**认知基准面**：将分类任务视为一个约束满足问题——目标不是找到"合理"的分类方案，而是找到唯一满足互斥性（任意两类无交集）和穷尽性（所有实体至少属于一类）这两个硬约束的正交维度对。

---

## Goal

基于 KG 中的现有分类标签与文献中已有的 taxonomy，诊断其缺陷（重叠、遗漏、模糊边界），提炼更本质的正交维度，重构一个能覆盖全部 Problem 节点且各类别互斥的新分类体系。

---

## Inputs

- `knowledge_graph/nodes/problems.json` — KG Problem 节点，含已有分类标签
- `knowledge_graph/nodes/concept_nodes.json` — 概念/类别节点（若有）
- `analyze_report/design_report.md` — RQ 定义与已知分类问题描述
- `paper_cards/parsed/` — 论文原文 Paper Cards，用于提取已有 taxonomy 描述
- `working_memory/rq_{id}/A1.1-a_matrix_report.json`（可选）— 上游矩阵映射结果

---

## Execution Steps

### Step 1: 提取现有分类体系

**为什么**：重构的起点是精确诊断旧体系的缺陷，而非凭空设计新体系。必须先收集文献中实际使用的分类方案，才能找到真正需要修复的痛点。

从 Paper Cards 的 Background / Related Work 章节提取文献中已有的分类方案：

```python
taxonomy_snippets = search_paper_sections(
    paper_cards_root="paper_cards/parsed",
    query="taxonomy classification categorize type category",
    paper_ids=all_paper_ids,
    topk=20
)
# 记录每种分类方案的：维度名称、标签集合、出现在多少篇论文中
existing_taxonomies = []
for snippet in taxonomy_snippets:
    taxonomy = judge(
        f"Extract the taxonomy or classification scheme from this text: '{snippet.paragraph_snippet}'. "
        f"Return: dimension_name, label_set, paper_id."
    )
    existing_taxonomies.append(taxonomy)
```

按引用频率排序，将被 ≥2 篇论文采用的分类方案列为「主流分类」，其余为「边缘分类」。

### Step 2: 诊断现有分类缺陷——操作化的 MECE 检验

**为什么**：MECE 检验必须是可计算的，而非主观判断。重叠检测用集合交集操作，遗漏检测用全集差集操作，两者都有明确的数值阈值。

**重叠检测**：对每对分类类别 (cat_A, cat_B)，获取各自的论文集合并计算交集：

```python
for cat_a, cat_b in combinations(all_categories, 2):
    # 获取每个类别覆盖的 Problem 节点集合
    papers_a = [p.id for p in all_problems if p.attributes.get("category") == cat_a]
    papers_b = [p.id for p in all_problems if p.attributes.get("category") == cat_b]
    
    overlap = intersect(papers_a, papers_b)
    
    if len(overlap) > 0:
        # 重叠存在：记录重叠的具体 problem_id 列表
        overlaps.append({
            "category_a": cat_a,
            "category_b": cat_b,
            "overlap_problems": overlap,
            "overlap_rate": len(overlap) / min(len(papers_a), len(papers_b))
        })
```

**遗漏检测**：计算所有类别的并集，与全量 Problem 节点集合做差：

```python
all_categorized = union(*[papers_per_category[cat] for cat in all_categories])
all_problem_ids = [p.id for p in get_entity_by_type(loader, "Problem")]
omitted = [pid for pid in all_problem_ids if pid not in all_categorized]

omission_rate = len(omitted) / len(all_problem_ids)
# omission_rate > 5% 时，旧分类体系的遗漏问题严重，必须重构
```

**模糊边界检测**：对上述重叠率 > 30% 的类别对，用 `search_paper_sections` 查找文献中对该边界的讨论：

```python
for overlap_pair in high_overlap_pairs:
    ambiguity_evidence = search_paper_sections(
        query=f"{overlap_pair.category_a} versus {overlap_pair.category_b} distinction difference",
        paper_ids=all_paper_ids,
        topk=3
    )
    # 若文献明确讨论了区分困难 → boundary_type: literature_acknowledged
    # 若文献无相关讨论 → boundary_type: empirically_observed
```

**必须引用文献中明确提到的"Limitations of existing taxonomy"作为重构依据。**

### Step 3: 推导正交重构维度

**为什么**：正交维度的选择不是头脑风暴，而是从 Problem 节点的 `description` 字段中归纳本质属性——找到那两个能把所有问题无歧义地放入唯一格子的属性。

分析 Problem 节点的底层属性，寻找满足以下条件的两个维度 A 和 B：
- A 和 B 的联合分布能覆盖所有已知 Problem 节点（穷尽性）
- A 的取值不依赖 B 的取值（正交性）
- 每个 Problem 节点只能归入一个 (A_i, B_j) 组合（互斥性）

```python
# 从 description 字段扫描潜在的本质属性
for p in all_problems:
    desc_analysis = judge(
        f"Given this problem description: '{p.description}', "
        f"identify 2-3 essential attributes that characterize this problem's NATURE "
        f"(not its surface appearance). Focus on: "
        f"(1) what structural property makes this problem possible, "
        f"(2) what system component is the locus of the problem."
    )
```

提出 3 组候选维度对后，验证正交性：对每对 (A, B) 计算 Cramer's V 或 Jaccard 相似度（数值 > 0.3 时维度不正交，须重新选择）。

**新分类维度的命名和取值必须与文献中使用的术语一致，禁止造词。**

### Step 4: 验证新分类体系——操作化覆盖率与互斥率计算

**为什么**：「覆盖率」和「互斥率」是新体系是否真正解决了旧体系缺陷的定量证明，必须通过实际的节点归类操作来计算，不能估算。

```python
classified = {}
multi_classified = []
unclassified = []

for p in all_problems:
    # 对每个 Problem 节点执行新分类
    a_val = get_entity_by_constraint(loader, "Problem", {
        "id": p.id, "dim_A_attribute": "*"
    })
    b_val = get_entity_by_constraint(loader, "Problem", {
        "id": p.id, "dim_B_attribute": "*"
    })
    
    if a_val and b_val:
        key = (a_val, b_val)
        classified[key] = classified.get(key, []) + [p.id]
    elif not a_val or not b_val:
        unclassified.append(p.id)

# 互斥性验证：每个 problem 只应出现在一个 (A_i, B_j) 格中
for p_id in all_problem_ids:
    appearances = sum(1 for cell in classified.values() if p_id in cell)
    if appearances > 1:
        multi_classified.append(p_id)

coverage_rate   = len([p for p in all_problem_ids if p not in unclassified]) / len(all_problem_ids)
exclusivity_rate = len([p for p in all_problem_ids if p not in multi_classified]) / len(all_problem_ids)
```

目标：覆盖率 > 95%，互斥率 = 100%。
- 覆盖率 < 90%：必须在报告中列出全部未归类节点，分析原因
- 互斥率 < 100%：必须找到并修复维度定义中的歧义点

### Step 5: 对抗性验证：检验新分类是否真正解决了旧体系的缺陷

**为什么**：新分类体系可能只是将旧体系的重叠问题从一处移到另一处，而非真正消除。必须逐一对照旧体系的已知缺陷，验证新体系是否实质性地解决了每一个。

```python
for old_defect in existing_taxonomy_diagnosis["overlaps"] + existing_taxonomy_diagnosis["omissions"]:
    # 检验新体系是否消除了该缺陷
    if old_defect.type == "overlap":
        # 检查原本重叠的 problem 节点在新体系中是否归入了不同的格子
        new_cells = {p_id: get_new_cell(p_id) for p_id in old_defect.overlap_problems}
        resolved = len(set(new_cells.values())) == len(new_cells)  # 每个都在不同格子
    elif old_defect.type == "omission":
        resolved = old_defect.problem_id not in unclassified
    
    resolution_status.append({
        "defect": old_defect,
        "resolved": resolved,
        "new_cell": new_cells if not resolved else "different_cells"
    })

# 若存在未解决的旧缺陷，必须在报告中说明原因并提出补救建议
unresolved_defects = [r for r in resolution_status if not r["resolved"]]
```

同时，检验新体系是否引入了新缺陷（新的高重叠类别对）：对新体系中所有类别对重新运行 Step 2 的交集检验。

### Step 6: 原文溯源验证

对所有分析结论中引用的证据，使用 `search_paper_sections` 工具在 `paper_cards/parsed/` 中精确定位原文片段：

```python
snippets = search_paper_sections(
    paper_cards_root="paper_cards/parsed",
    query="<分析结论的关键词>",
    paper_ids=[<涉及的paper_id列表>],
    topk=3
)
```

每条关键结论必须附带：
- `paper_id`：来源论文ID（对应 `knowledge_graph/nodes/papers.json` 中的记录）
- `section`：原文章节标题
- `paragraph_snippet`：原文片段（≥20字，直接引用，禁止改写）
- `score`：语义相似度分值

**无法找到原文片段支撑的结论必须标注 `evidence: unverified`，不得作为最终结论输出。**

## Key Rules

- **重构依据必须引用文献**：必须能找到至少一篇论文明确批评了现有分类的局限性，作为重构动机的文献证据。
- 若文献集中无明确的分类批评，可从 Problem 节点的重叠归类现象中推断，但需标注 `diagnosis_source: empirical_observation`。
- 新分类维度的命名和取值必须与文献中使用的术语一致，禁止造词。
- 覆盖率 < 90% 时，必须在报告中列出未能归类的 Problem 节点并分析原因，不得忽略。
- 正交性验证必须计算 Cramer's V 或 Jaccard 相似度，数值 > 0.3 时需重新审视维度选择。
- MECE 验证必须是操作化的：重叠检测用 `intersect` 工具计算实际集合交集，遗漏检测用 `union` + 差集计算，不得用主观判断替代数值计算。
- **认知基准面纪律**：整个分析过程必须以「约束满足」而非「合理性」为判断标准——一个维度对只要满足互斥性和穷尽性的硬约束就是合格的，不需要额外证明其"直觉合理性"；反之，一个直觉合理但 Cramer's V > 0.3 的维度对必须被拒绝。
